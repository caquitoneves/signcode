# Roteiro de vídeo — Aula 6.5: Interrompendo um loop

**Módulo 6 — Repetições** · Duração alvo: ~5 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Usar break e continue

## Termos técnicos a preparar antes
- **break** — datilologia + explicar: para o loop de vez.
- **continue** — datilologia + explicar: pula só a volta atual.
- Esta aula tem desafio de código (m6-break).

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** prático; dois comandos bem distintos.
- **Enquadramento:** meio-corpo; os dois exemplos lado a lado.

## Roteiro (frase a frase)

### 1. Abertura · ~35s
*Expressão: clara · Ritmo: lento · Corpo: 'parar' × 'pular'*
- "break para o loop imediatamente."
- "continue pula só a volta atual e segue."

### 2. break · ~55s
*Expressão: didática · Ritmo: lento · Corpo: gesto de parar seco*
- `[MOSTRAR NA TELA: for (i=1; i<=10; i++) { if (i===4) break; console.log(i); } → 1 2 3]`
- "Enquanto i vai de um a dez: se i for quatro, break."
- "O loop para de vez. Mostra só um, dois, três."

### 3. continue · ~55s
*Expressão: didática · Ritmo: lento · Corpo: gesto de pular por cima*
- `[MOSTRAR NA TELA: for (i=1; i<=5; i++) { if (i===3) continue; console.log(i); } → 1 2 4 5]`
- "Se i for três, continue: pula só essa volta."
- "Mostra um, dois, quatro, cinco. O três foi pulado."
- `[MOSTRAR NA TELA: break = encerra o loop · continue = pula para a próxima volta]`

### 4. Desafio de código · ~70s
*Expressão: incentivadora · Ritmo: lento*
- `[MOSTRAR NA TELA: desafio m6-break — pare no primeiro número divisível por 7, guarde em primeiro]`
- "No desafio: percorra de um a cem."
- "Pare, com break, no primeiro número divisível por sete."
- "Guarde esse número em primeiro. A resposta é sete."

### 5. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: break sai do loop; continue pula uma volta."
- "Ótimos para 'achou, pode parar'."
- "Na próxima aula: evitando loops infinitos."
