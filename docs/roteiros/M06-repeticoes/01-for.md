# Roteiro de vídeo — Aula 6.1: O laço for

**Módulo 6 — Repetições** · Duração alvo: ~6m30s
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Escrever um for
- Entender início, condição e passo

## Termos técnicos a preparar antes
- **for** — datilologia; use quando se sabe quantas vezes repetir.
- **início / condição / passo** — as três partes. Sinais consistentes.
- **i++ ** — explicar: "aumenta um".
- Esta aula tem desafio de código (m6-for).

## Visão geral de gravação
- **Ritmo geral:** lento; o for tem três partes, é denso.
- **Tom predominante:** metódico.
- **Enquadramento:** meio-corpo; a estrutura e a tabela de voltas na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~30s
*Expressão: clara · Ritmo: lento*
- "O for é ideal quando você sabe quantas vezes quer repetir."

### 2. As três partes · ~90s
*Expressão: didática · Ritmo: lento, uma parte por vez · Corpo: marque as três partes no espaço*
- `[MOSTRAR NA TELA: for ( início ; condição ; passo ) { } → let i=1 ; i<=5 ; i++]`
- "O for tem três partes, separadas por ponto e vírgula."
- "Início: let i recebe um. De onde começa."
- "Condição: i menor ou igual a cinco. Enquanto for verdade, repete."
- "Passo: i mais mais. O que muda a cada volta."

### 3. Exemplo e as voltas · ~110s
*Expressão: narrativa · Ritmo: lento · Corpo: conte as voltas*
- `[MOSTRAR NA TELA: for (let i=1; i<=5; i++) { console.log(i); } → 1 2 3 4 5]`
- "Esse for mostra um, dois, três, quatro, cinco."
- `[MOSTRAR NA TELA: tabela — volta 1: i=1 true · ... · volta 6: i=6 false para]`
- "Na primeira volta, i vale um, a condição é verdadeira, mostra um."
- "Vai subindo até cinco."
- "Na sexta volta, i vale seis, a condição fica falsa, e o loop para."

### 4. Desafio de código · ~70s
*Expressão: incentivadora · Ritmo: lento*
- `[MOSTRAR NA TELA: desafio m6-for — some todos os números de 1 a 10 em total]`
- "No desafio: use um for para somar todos os números de um até dez."
- "Guarde o resultado em total. A resposta é cinquenta e cinco."

### 5. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: for início, condição, passo — repete um número controlado de vezes."
- "Na próxima aula: o laço while."
