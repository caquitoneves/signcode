# Roteiro de vídeo — Aula 10.0: O que é o DOM?

**Módulo 10 — JavaScript no Navegador** · Duração alvo: ~5 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Entender o que é o DOM

## Termos técnicos a preparar antes
- **DOM** — datilologia + explicar: a página vista pelo JavaScript, como uma árvore.
- Ponto-chave: o JS mexe no DOM ao vivo, não no arquivo HTML.

## Visão geral de gravação
- **Ritmo geral:** médio; abre o módulo em que a página ganha vida.
- **Tom predominante:** animado.
- **Enquadramento:** meio-corpo; a árvore do DOM na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~40s
*Expressão: 'agora a página reage' · Ritmo: lento*
- "O DOM é a página vista pelo JavaScript."
- "Uma árvore de elementos."
- "O código pode ler e mudar essa árvore ao vivo."

### 2. A árvore · ~70s
*Expressão: didática · Ritmo: lento · Corpo: desenhe a árvore de cima para baixo*
- `[MOSTRAR NA TELA: document → html → body → h1, button]`
- "No topo, o document."
- "Dentro, o html. Dentro dele, o body."
- "E dentro do body, os elementos: o h1, o button."

### 3. O ponto importante · ~40s
*Expressão: esclarecedora · Ritmo: lento*
- "Dica importante:"
- "Quando o JavaScript muda a página — troca um texto, esconde algo —"
- "ele mexe no DOM. Não no arquivo HTML."

### 4. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: DOM é a página como árvore de elementos."
- "É por ele que o JavaScript deixa a página viva."
- "Na próxima aula: selecionar elementos."
