# Roteiro de vídeo — Aula 10.8: Debugging no navegador

**Módulo 10 — JavaScript no Navegador** · Duração alvo: ~5m30s
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Usar console e DevTools

## Termos técnicos a preparar antes
- **DevTools (F12) / Console** — datilologia; as ferramentas do navegador.
- **console.log / console.table** — ver valores / ver listas em tabela.

## Visão geral de gravação
- **Ritmo geral:** médio; fecha o módulo.
- **Tom predominante:** de aliado (o console é seu amigo).
- **Enquadramento:** meio-corpo; os comandos e o caminho na tela. Ideal: screencast das DevTools.

## Roteiro (frase a frase)

### 1. Abertura · ~35s
*Expressão: tranquilizadora · Ritmo: lento*
- "Todo navegador tem as DevTools. Abra com F12."
- "O console é seu melhor amigo para achar erros."

### 2. Investigando · ~70s
*Expressão: didática · Ritmo: lento*
- `[MOSTRAR NA TELA: console.log("cheguei aqui", variavel); console.table(lista);]`
- "console.log mostra valores. Dá para ver se o código chegou ali e o que a variável tem."
- "console.table mostra listas em formato de tabela."

### 3. O caminho · ~60s
*Expressão: metódica · Ritmo: lento · Corpo: siga os passos*
- `[MOSTRAR NA TELA: Deu erro → abre o Console (F12) → lê a mensagem → console.log rastreia → corrige]`
- "Deu erro? Abra o Console, com F12."
- "Leia a mensagem."
- "Use console.log para rastrear."
- "E corrija."
- "Dica: a aba Console mostra erros em vermelho, com o número da linha."
- "Leia a mensagem: ela quase sempre aponta o caminho."

### 4. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: F12 abre as DevTools; console.log mostra valores; a aba Console revela os erros."
- "No próximo módulo: Git e GitHub."

**Soma estimada:** ~3m05s (alvo: ~5m30s — ideal com screencast das DevTools)
