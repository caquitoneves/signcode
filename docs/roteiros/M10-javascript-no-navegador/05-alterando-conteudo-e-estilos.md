# Roteiro de vídeo — Aula 10.5: Alterando conteúdo e estilos

**Módulo 10 — JavaScript no Navegador** · Duração alvo: ~5m30s
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Mudar textContent e classes

## Termos técnicos a preparar antes
- **textContent** — trocar o texto.
- **classList.add / classList.toggle** — adicionar / ligar-desligar classe.
- Boa prática: trocar classes (CSS) em vez de escrever estilo direto no JS.

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** prático.
- **Enquadramento:** meio-corpo; os comandos na tela. Ideal: demo ao vivo.

## Roteiro (frase a frase)

### 1. Abertura · ~35s
*Expressão: animada · Ritmo: lento*
- "Com o elemento selecionado, o JavaScript muda texto, conteúdo e estilo."
- "Tudo ao vivo."

### 2. Mudando · ~90s
*Expressão: didática · Ritmo: lento · Corpo: aponte cada ação*
- `[MOSTRAR NA TELA: titulo.textContent = "Novo título"; titulo.classList.add("destaque"); titulo.classList.toggle("ativo");]`
- "Ponto textContent troca o texto."
- "Ponto classList ponto add adiciona uma classe CSS."
- "Ponto classList ponto toggle liga e desliga a classe."
- `[MOSTRAR NA TELA: trocar texto → .textContent · adicionar classe → .classList.add · ligar/desligar → .classList.toggle]`

### 3. A boa prática · ~45s
*Expressão: conselho · Ritmo: lento*
- "Dica: prefira trocar classes, definidas no CSS."
- "Em vez de escrever estilo direto no JavaScript."
- "Assim o visual fica no CSS, onde deve estar."

### 4. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: ponto textContent muda o texto; ponto classList liga e desliga classes CSS."
- "Na próxima aula: estado simples."

**Soma estimada:** ~3m10s (alvo: ~5m30s — ideal demonstrar a mudança ao vivo)
