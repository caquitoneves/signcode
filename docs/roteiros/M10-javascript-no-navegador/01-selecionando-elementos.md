# Roteiro de vídeo — Aula 10.1: Selecionando elementos

**Módulo 10 — JavaScript no Navegador** · Duração alvo: ~5m30s
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Selecionar elementos com querySelector

## Termos técnicos a preparar antes
- **querySelector / querySelectorAll** — datilologia; achar um / achar vários.
- Ponto-chave: usa a mesma sintaxe do CSS ("h1", ".classe", "#id").

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** prático; ponte HTML ↔ JS.
- **Enquadramento:** meio-corpo; os seletores e a ponte na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~35s
*Expressão: clara · Ritmo: lento*
- "Antes de mudar algo, o JavaScript precisa encontrar o elemento."
- "O jeito moderno é o querySelector."

### 2. Selecionando · ~80s
*Expressão: didática · Ritmo: lento*
- `[MOSTRAR NA TELA: document.querySelector("h1") · querySelector("#enviar") · querySelectorAll(".item")]`
- "document ponto querySelector, h1: pega o primeiro h1."
- "querySelector, cerquilha enviar: pega por id."
- "querySelectorAll, ponto item: pega vários, todos da classe item."

### 3. A ponte HTML ↔ JS · ~60s
*Expressão: 'veja a conexão' · Ritmo: lento · Corpo: um lado HTML, outro JS*
- `[MOSTRAR NA TELA: HTML <h1>Olá</h1> → querySelector("h1") → JS const titulo = ...]`
- "No HTML existe o h1."
- "O querySelector faz a ponte."
- "Agora, no JavaScript, dá para mudar esse elemento."
- "Dica: o querySelector usa a mesma sintaxe do CSS. h1, ponto classe, cerquilha id."

### 4. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: document ponto querySelector acha um elemento; querySelectorAll acha vários."
- "Na próxima aula: eventos."

**Soma estimada:** ~3m15s (alvo: ~5m30s)
