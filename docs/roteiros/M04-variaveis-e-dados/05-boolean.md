# Roteiro de vídeo — Aula 4.5: Boolean (verdadeiro/falso)

**Módulo 4 — Variáveis e Dados** · Duração alvo: ~5 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Usar valores booleanos
- Ligar booleanos a comparações

## Termos técnicos a preparar antes
- **Boolean** — datilologia + explicar: só dois valores.
- **true / false** — reaproveite os sinais de verdadeiro/falso do Módulo 2.
- **=== (igual a) · > (maior que)** — comparações (aprofundam no Módulo 5).

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** conector — liga com o Módulo 2 e prepara o if.
- **Enquadramento:** meio-corpo; exemplos e comparações na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~35s
*Expressão: precisa · Ritmo: lento · Corpo: dois valores, dois lados*
- "Boolean só tem dois valores."
- "true, verdadeiro. E false, falso."
- "É a base das decisões."

### 2. Exemplo · ~45s
*Expressão: didática · Ritmo: lento*
- `[MOSTRAR NA TELA: const maiorDeIdade = true; const chovendo = false;]`
- "maiorDeIdade recebe true."
- "chovendo recebe false."

### 3. De onde vêm os booleanos · ~70s
*Expressão: 'lembra do Módulo 2?' · Ritmo: lento · Corpo: pergunta → resposta true/false*
- "Comparações produzem booleanos. Lembra do Módulo 2?"
- `[MOSTRAR NA TELA: 10 > 5 → true · 3 === 4 → false]`
- "Dez é maior que cinco? true."
- "Três é igual a quatro? false."

### 4. A conexão · ~30s
*Expressão: antecipando · Ritmo: médio*
- "Uma conexão importante:"
- "No próximo módulo, o if vai usar booleanos para decidir o que o programa faz."

### 5. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: boolean é true ou false."
- "Comparações geram booleanos e alimentam as decisões."
- "Na próxima aula: null e undefined."
