# Roteiro de vídeo — Aula 4.4: Numbers (números)

**Módulo 4 — Variáveis e Dados** · Duração alvo: ~5 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Usar valores numéricos
- Fazer contas com operadores

## Termos técnicos a preparar antes
- **Number** — datilologia + explicar: número, SEM aspas.
- **+ - * /** — os quatro operadores. Sinais claros.
- Alerta-chave: "10" com aspas é texto, não número.

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** prático; alerta no fim sobre aspas.
- **Enquadramento:** meio-corpo; tabela de operações na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~30s
*Expressão: clara · Ritmo: lento · Corpo: 'sem aspas' bem marcado*
- "Number é número. Sem aspas."
- "Serve para fazer contas."

### 2. As operações · ~90s
*Expressão: didática · Ritmo: lento · Corpo: aponte cada operação*
- `[MOSTRAR NA TELA: const preco = 10; const desconto = 3; preco - desconto → 7; preco * 2 → 20]`
- "preco recebe dez. desconto recebe três."
- "preco menos desconto dá sete."
- "preco vezes dois dá vinte."
- `[MOSTRAR NA TELA: + somar · - subtrair · * multiplicar · / dividir]`
- "Mais soma, menos subtrai, asterisco multiplica, barra divide."

### 3. O alerta das aspas · ~50s
*Expressão: alerta amigável · Ritmo: lento · Corpo: contraste com e sem aspas*
- "Cuidado:"
- "Número vai sem aspas."
- "Dez entre aspas é texto, não número."
- "E isso muda tudo. Veremos na aula de conversão de tipos."

### 4. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: number é número sem aspas."
- "Dá para somar, subtrair, multiplicar e dividir."
- "Na próxima aula: boolean, verdadeiro e falso."
