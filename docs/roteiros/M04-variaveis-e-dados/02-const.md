# Roteiro de vídeo — Aula 4.2: A palavra const

**Módulo 4 — Variáveis e Dados** · Duração alvo: ~5 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Declarar constantes com const
- Escolher entre let e const

## Termos técnicos a preparar antes
- **const** — datilologia; "valor fixo, não muda". É a escolha padrão.
- Contraste com **let** (valor que muda).

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** de boa prática — "comece sempre por const".
- **Enquadramento:** meio-corpo; a árvore de decisão let/const na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~30s
*Expressão: clara · Ritmo: lento*
- "Use const quando o valor não deve mudar."
- "É a escolha padrão."

### 2. Exemplo · ~60s
*Expressão: didática · Ritmo: lento · Corpo: gesto de 'travado' ao mostrar o erro*
- `[MOSTRAR NA TELA: const pi = 3.14; const nomeDoApp = "SignCode"; // pi = 4 daria erro]`
- "const pi recebe três vírgula catorze."
- "const nomeDoApp recebe SignCode."
- "Se você tentar mudar o pi depois, dá erro. Ele é fixo."

### 3. let ou const? · ~70s
*Expressão: orientadora · Ritmo: lento · Corpo: bifurcação com as mãos*
- `[MOSTRAR NA TELA: 'O valor vai mudar?' → sim: let · não: const (comece por aqui)]`
- "A pergunta é: o valor vai mudar?"
- "Se sim: let."
- "Se não: const."
- "Boa prática: comece sempre por const."
- "Só troque para let quando perceber que precisa mudar o valor."

### 4. Pergunta de fixação · ~25s
*Expressão: pergunta, depois confirmação*
- `[MOSTRAR NA TELA: "Quando usar const?"]`
- "Quando usar const?" *(pausa)*
- "Resposta: quando o valor não vai mudar."

### 5. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: const é valor fixo. É a escolha segura por padrão."
- "Na próxima aula: strings, o texto."
