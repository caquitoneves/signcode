# Roteiro de vídeo — Aula 0.1: O que é programação?

**Módulo 0 — Bem-vindo à Tecnologia** · Duração alvo: ~6 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Compreender programação como criação de instruções
- Reconhecer algoritmos no dia a dia

## Termos técnicos a preparar antes
- **Programar** — manter o mesmo sinal da aula anterior.
- **Algoritmo** — termo-chave desta aula. Defina um sinal claro (ou datilologia + explicação). Vai voltar muitas vezes no curso.
- **Instrução / passo** — escolha um sinal consistente para "passo".

## Visão geral de gravação
- **Ritmo geral:** médio; desacelere no exemplo do café.
- **Tom predominante:** didático e próximo, como quem conta um segredo simples.
- **Enquadramento:** meio-corpo. Reserve a tela lateral para os diagramas.

## Roteiro (frase a frase)

### 1. Abertura · ~40s
*Expressão: convidativa · Ritmo: lento · Corpo: um dedo erguido para 'uma frase só'*
- "Nesta aula: o que é programação, em uma frase só."
- "Programar é escrever instruções que o computador consegue seguir."
- "Instruções para resolver um problema."

### 2. Pensar antes de digitar · ~70s
*Expressão: alerta, sobrancelhas levemente erguidas no contraste 'rápido × não esperto' · Ritmo: médio com pausa após cada contraste*
- "O computador é rápido. Mas ele não é esperto."
- "Ele faz exatamente o que você mandar."
- "E na ordem que você mandar." *(pausa)*
- "Por isso o mais importante não é digitar."
- "O mais importante é pensar na solução."

### 3. Você já cria algoritmos · ~110s
*Expressão: leve, cotidiana (exemplo do café) · Ritmo: lento, marcando cada passo no espaço · Corpo: enumere os passos com a mão*
- "Um algoritmo é uma sequência de passos para chegar a um resultado."
- "Você já faz isso todo dia."
- "Fazer um café é um algoritmo."
- `[MOSTRAR NA TELA: passos do café — 1 pegar a xícara · 2 colocar o café · 3 aquecer a água · 4 colocar a água · 5 misturar → café pronto]`
- "Passo um: pegar a xícara."
- "Passo dois: colocar o café."
- "E assim por diante, até o café ficar pronto."
- "Todo programa segue este caminho:"
- `[MOSTRAR NA TELA: PROBLEMA → PASSOS → INSTRUÇÕES → RESULTADO]`

### 4. Prática · ~50s
*Expressão: incentivo · Ritmo: lento · Corpo: gesto de 'sua vez'*
- "Agora é sua vez."
- "Escreva pelo menos cinco passos para se preparar para sair de casa."
- "Teste: se outra pessoa seguir seus passos exatamente, ela consegue?"
- "Se ficar confuso, é porque falta um passo."

### 5. Pergunta de fixação · ~35s
*Expressão: pergunta (sobrancelhas erguidas), depois afirmação confiante na resposta · Ritmo: pausa entre pergunta e resposta*
- `[MOSTRAR NA TELA: "O que significa programar?"]`
- "O que significa programar?" *(segure a pausa)*
- "Resposta: escrever instruções para resolver um problema."
- "Não é digitar rápido. Não é consertar a parte física."

### 6. Fechamento · ~35s
*Expressão: conclusiva, tranquila · Ritmo: lento*
- "Resumo: uma sequência organizada de instruções é um algoritmo."
- "E o algoritmo é a base de toda programação."
- "Na próxima aula: a diferença entre ideia, algoritmo e código."
