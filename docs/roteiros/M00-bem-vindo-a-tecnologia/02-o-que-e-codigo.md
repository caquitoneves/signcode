# Roteiro de vídeo — Aula 0.2: O que é código?

**Módulo 0 — Bem-vindo à Tecnologia** · Duração alvo: ~6 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Diferenciar ideia, algoritmo e código

## Termos técnicos a preparar antes
- **Ideia / algoritmo / código** — os três conceitos da aula. Defina um sinal para cada e deixe claro que são coisas diferentes.
- **console.log** — primeira aparição de código real. Datilologia + explicar "mostrar na tela". Não precisa de sinal próprio.

## Visão geral de gravação
- **Ritmo geral:** lento; é um conceito que costuma confundir.
- **Tom predominante:** esclarecedor, de quem desfaz uma confusão com calma.
- **Enquadramento:** meio-corpo; use a altura das mãos para representar os três degraus (de cima para baixo).

## Roteiro (frase a frase)

### 1. Abertura · ~40s
*Expressão: alerta amigável (sobrancelhas erguidas em 'cuidado') · Ritmo: lento · Corpo: gesto de 'atenção'*
- "Cuidado com uma confusão muito comum."
- "Código não é a mesma coisa que a ideia."
- "O código é só o último passo."

### 2. Os três degraus · ~110s
*Expressão: didática · Ritmo: lento, uma ideia por degrau · Corpo: marque cada degrau numa altura diferente, de cima para baixo*
- "Pense em três degraus, de cima para baixo."
- `[MOSTRAR NA TELA: IDEIA → ALGORITMO → CÓDIGO → COMPUTADOR mostra: Olá!]`
- "Primeiro degrau: a ideia. Por exemplo: quero mostrar uma mensagem."
- "Segundo degrau: o algoritmo. Escrever a mensagem na tela."
- "Terceiro degrau: o código. O texto que o computador entende."
- "No fim, o computador mostra o resultado."

### 3. Vendo na prática · ~110s
*Expressão: concreta, 'olha só' · Ritmo: médio; desacelere ao apresentar o código · Corpo: aponte para a tela ao citar o código*
- "A mesma ideia, descendo os degraus."
- "Ideia: quero cumprimentar quem abrir meu programa."
- "Algoritmo: escrever a frase Olá na tela."
- "Código:"
- `[MOSTRAR NA TELA: console.log(\"Olá!\");]`
- "Esse comando — console ponto log — é o jeito do JavaScript de escrever na tela."
- "Você vai usar muito isso."

### 4. Pergunta de fixação · ~30s
*Expressão: pergunta, depois confirmação · Ritmo: pausa entre pergunta e resposta*
- `[MOSTRAR NA TELA: "Qual é a ordem correta ao resolver um problema?"]`
- "Qual é a ordem certa?" *(segure a pausa)*
- "Resposta: primeiro a ideia, depois o algoritmo, por fim o código."

### 5. Fechamento · ~30s
*Expressão: conclusiva, encorajadora · Ritmo: lento*
- "Resumo: primeiro a ideia, depois os passos, só então o código."
- "Pular direto para o código é o que mais trava quem começa."
- "Na próxima aula: o que faz, de verdade, uma pessoa desenvolvedora."

**Soma estimada:** ~5m20s (alvo: ~6 min)
