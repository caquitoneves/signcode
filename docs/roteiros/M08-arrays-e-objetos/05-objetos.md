# Roteiro de vídeo — Aula 8.5: Objetos

**Módulo 8 — Arrays e Objetos** · Duração alvo: ~5m30s
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Criar e ler objetos

## Termos técnicos a preparar antes
- **Objeto** — datilologia; metáfora: ficha com rótulos.
- **Propriedade (chave: valor)** — explicar.
- **objeto.propriedade** — acesso por rótulo.
- Esta aula tem desafio de código (m8-nome).

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** didático; contraste com array.
- **Enquadramento:** meio-corpo; o objeto e o acesso na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~30s
*Expressão: clara · Ritmo: lento · Corpo: gesto de ficha*
- "Objeto é uma ficha."
- "Dados com rótulos, as propriedades, dentro de chaves."

### 2. Criar e ler · ~75s
*Expressão: didática · Ritmo: lento*
- `[MOSTRAR NA TELA: const aluno = { nome:"Ana", nota:9, aprovado:true }; aluno.nome → Ana; aluno.nota → 9]`
- "aluno recebe nome Ana, nota nove, aprovado true."
- "aluno ponto nome dá Ana."
- "aluno ponto nota dá nove."

### 3. Array × objeto · ~55s
*Expressão: comparativa · Ritmo: lento · Corpo: posição × rótulo*
- `[MOSTRAR NA TELA: ARRAY → lista[0] (posição) · OBJETO → aluno.nome (rótulo)]`
- "No array, o acesso é por posição: lista colchete zero."
- "No objeto, por rótulo: aluno ponto nome."
- "Dica: aluno ponto nota recebe dez atualiza a nota."

### 4. Desafio de código · ~70s
*Expressão: incentivadora · Ritmo: lento*
- `[MOSTRAR NA TELA: desafio m8-nome — nomeDoAluno(aluno) retorna aluno.nome]`
- "No desafio: crie a função nomeDoAluno, que recebe um objeto com a propriedade nome."
- "Ela retorna esse nome."
- "nomeDoAluno de um objeto com nome Ana devolve Ana."

### 5. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: objeto chaves chave dois-pontos valor guarda dados com nome."
- "Acesse com objeto ponto chave."
- "Na próxima aula: array de objetos."

**Soma estimada:** ~4m10s (alvo: ~5m30s)
