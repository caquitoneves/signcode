## Objetivo da aula
- Conhecer filter e map

## Termos técnicos a preparar antes
- **filter** — datilologia + explicar: separa itens por uma condição.
- **map** — datilologia + explicar: transforma cada item.
- Reaproveite arrow functions (Módulo 7).

## Visão geral de gravação
- **Ritmo geral:** médio; dois métodos poderosos.
- **Tom predominante:** 'ferramentas de gente grande', ainda acessíveis.
- **Enquadramento:** meio-corpo; filter e map na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~35s
*Expressão: 'vou te mostrar algo poderoso' · Ritmo: lento*
- "Além do loop, arrays têm métodos poderosos."
- "Para filtrar e transformar: filter e map."

### 2. filter — separa · ~70s
*Expressão: didática · Ritmo: lento · Corpo: gesto de peneirar*
- `[MOSTRAR NA TELA: const notas = [4,8,6,3,9]; notas.filter((n) => n >= 6) → [8,6,9]]`
- "filter separa."
- "notas ponto filter, com a arrow: n maior ou igual a seis."
- "Sobram só as aprovadas: oito, seis, nove."

### 3. map — transforma · ~70s
*Expressão: didática · Ritmo: lento · Corpo: gesto de transformar cada um*
- `[MOSTRAR NA TELA: notas.map((n) => n * 2) → [8,16,12,6,18]]`
- "map transforma cada item."
- "notas ponto map, com a arrow: n vezes dois."
- "Cada nota é dobrada."
- `[MOSTRAR NA TELA: filter → lista menor (ou igual) · map → lista do mesmo tamanho]`
- "filter devolve uma lista menor. map devolve uma do mesmo tamanho."

### 4. A conexão com arrow · ~35s
*Expressão: 'por isso você aprendeu arrow' · Ritmo: médio*
- "Repare: filter e map usam arrow functions, do Módulo 7."
- "Por isso elas são tão comuns."

### 5. Fechamento · ~25s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: filter separa por uma condição; map transforma cada item."
- "Nenhum dos dois mexe no array original."
