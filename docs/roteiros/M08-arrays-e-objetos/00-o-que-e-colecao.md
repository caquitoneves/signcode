# Roteiro de vídeo — Aula 8.0: O que é uma coleção?

**Módulo 8 — Arrays e Objetos** · Duração alvo: ~5 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Entender por que agrupar dados

## Termos técnicos a preparar antes
- **Coleção** — explicar: vários dados juntos.
- **Array (lista) × objeto (ficha)** — apresente os dois; aprofundam nas próximas aulas.

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** motivador do módulo.
- **Enquadramento:** meio-corpo; array × objeto lado a lado na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~35s
*Expressão: clara · Ritmo: lento*
- "Em vez de uma variável por valor, uma coleção guarda vários dados juntos."
- "Organizados."

### 2. O problema · ~45s
*Expressão: 'veja o trabalho' · Ritmo: médio*
- `[MOSTRAR NA TELA: const aluno1 = "Ana"; const aluno2 = "Caio"; const aluno3 = "Bia"; // e se forem 300?]`
- "aluno um, aluno dois, aluno três..."
- "E se forem trezentos alunos? Impossível assim."

### 3. Duas coleções principais · ~70s
*Expressão: didática · Ritmo: lento · Corpo: array de um lado, objeto do outro*
- `[MOSTRAR NA TELA: ARRAY ["Ana","Caio","Bia"] (ordem por posição) · OBJETO { nome:"Ana", nota:9 } (dados com rótulos)]`
- "O array é uma lista. A ordem vem pela posição."
- "O objeto é uma ficha. Cada dado tem um rótulo."
- "Dica: array quando a ordem importa, como uma fila."
- "Objeto quando cada dado tem um nome, como uma ficha."

### 4. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: coleção é vários valores juntos."
- "Array guarda por posição; objeto por rótulo."
- "Na próxima aula: arrays."

**Soma estimada:** ~2m50s (alvo: ~5 min)
