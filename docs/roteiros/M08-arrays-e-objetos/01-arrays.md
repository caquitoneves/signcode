# Roteiro de vídeo — Aula 8.1: Arrays (listas)

**Módulo 8 — Arrays e Objetos** · Duração alvo: ~5 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Criar um array
- Ler o tamanho com .length

## Termos técnicos a preparar antes
- **Array** — datilologia; lista dentro de colchetes.
- **Índice** — posição; começa em 0. Ponto crucial.
- **.length** — tamanho.
- Esta aula tem desafio de código (m8-maior).

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** fundamental; "índices começam em 0".
- **Enquadramento:** meio-corpo; array com índices na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~30s
*Expressão: clara · Ritmo: lento · Corpo: gesto de colchetes*
- "Array é uma lista de valores, em ordem, dentro de colchetes."

### 2. Criar e medir · ~60s
*Expressão: didática · Ritmo: lento*
- `[MOSTRAR NA TELA: const frutas = ["maçã","banana","uva"]; frutas.length → 3]`
- "frutas recebe maçã, banana, uva."
- "frutas ponto length dá três: são três itens."

### 3. Cada item tem uma posição · ~75s
*Expressão: enfática no 'zero' · Ritmo: lento · Corpo: conte 0, 1, 2*
- `[MOSTRAR NA TELA: ["maçã","banana","uva"] → índices 0, 1, 2]`
- "Atenção a isto: os índices começam em zero."
- "maçã é a posição zero. banana, a posição um. uva, a posição dois."
- "Dica: o último item é sempre length menos um."

### 4. Desafio de código · ~70s
*Expressão: incentivadora · Ritmo: lento*
- `[MOSTRAR NA TELA: desafio m8-maior — maior(numeros) retorna o maior número do array]`
- "No desafio: crie a função maior, que recebe um array."
- "Ela retorna o maior número do array."
- "maior de três, nove, dois é nove."

### 5. Pergunta de fixação · ~30s
*Expressão: pergunta, depois confirmação*
- `[MOSTRAR NA TELA: "Como acessar o primeiro item de 'lista'?"]`
- "Como acessar o primeiro item de um array chamado lista?" *(pausa)*
- "Resposta: lista, colchete, zero. Arrays começam no zero."

### 6. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: array colchetes guarda uma lista ordenada. Ponto length diz quantos."
- "Na próxima aula: índices."
