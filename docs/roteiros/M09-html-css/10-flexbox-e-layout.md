# Roteiro de vídeo — Aula 9.10: Flexbox e layout

**Módulo 9 — HTML + CSS** · Duração alvo: ~6m30s
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Usar flexbox para layout

## Termos técnicos a preparar antes
- **Flexbox / display: flex** — datilologia; organiza em linha ou coluna.
- **justify-content / align-items / gap** — datilologia; explique cada um.
- **row / column** — as duas direções.

## Visão geral de gravação
- **Ritmo geral:** lento; layout é abstrato, use muito a tela.
- **Tom predominante:** prático; "base do layout moderno".
- **Enquadramento:** meio-corpo; row × column na tela. Ideal: demo ao vivo.

## Roteiro (frase a frase)

### 1. Abertura · ~35s
*Expressão: clara · Ritmo: lento*
- "Flexbox organiza elementos em linha ou coluna."
- "Com alinhamento fácil. É a base do layout moderno."

### 2. Ligando o flex · ~80s
*Expressão: didática · Ritmo: lento*
- `[MOSTRAR NA TELA: .container { display: flex; gap: 16px; justify-content: center; align-items: center; }]`
- "display flex liga o flexbox no container."
- "gap dá o espaço entre os itens."
- "justify-content alinha numa direção."
- "align-items alinha na outra."

### 3. As duas direções · ~70s
*Expressão: 'veja a diferença' · Ritmo: lento · Corpo: lado a lado × empilhado*
- `[MOSTRAR NA TELA: flex-direction: row → [A][B][C] lado a lado · column → A/B/C empilhado]`
- "row: os itens ficam lado a lado."
- "column: os itens ficam empilhados."
- "Dica: justify-content alinha no sentido da direção."
- "align-items, no sentido oposto. gap dá o espaço entre os itens."

### 4. Fechamento · ~25s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: display flex cria layout flexível."
- "justify-content e align-items alinham; gap espaça."
- "Na próxima aula: responsividade e acessibilidade visual."

**Soma estimada:** ~3m30s (alvo: ~6m30s — ideal demonstrar ao vivo movendo os itens)
