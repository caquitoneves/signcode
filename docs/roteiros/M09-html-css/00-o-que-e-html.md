# Roteiro de vídeo — Aula 9.0: O que é HTML?

**Módulo 9 — HTML + CSS** · Duração alvo: ~5 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Entender o papel do HTML

## Termos técnicos a preparar antes
- **HTML** — datilologia; a estrutura/esqueleto da página.
- **CSS / JS** — datilologia; apenas citados (visual e comportamento).
- Metáfora: casa (HTML paredes, CSS pintura, JS elétrica).

## Visão geral de gravação
- **Ritmo geral:** médio; abre o módulo mais visual do curso.
- **Tom predominante:** animado — "ver o código virar página".
- **Enquadramento:** meio-corpo; as três camadas na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~35s
*Expressão: animada · Ritmo: lento · Corpo: gesto de esqueleto/estrutura*
- "HTML dá a estrutura da página."
- "Títulos, textos, imagens, botões."
- "É o esqueleto."

### 2. As três camadas da web · ~70s
*Expressão: didática · Ritmo: lento · Corpo: três níveis no espaço*
- `[MOSTRAR NA TELA: HTML → estrutura · CSS → visual · JS → comportamento]`
- "HTML: a estrutura, o conteúdo."
- "CSS: o visual, cores e layout."
- "JavaScript: o comportamento, as reações."
- "Dica: pense numa casa."
- "HTML são as paredes. CSS é a pintura. JavaScript é a parte elétrica que reage."

### 3. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: HTML é a estrutura e o conteúdo da página."
- "CSS pinta, JavaScript dá vida — nos próximos módulos."
- "Na próxima aula: a estrutura de uma página."

**Soma estimada:** ~2m05s (alvo: ~5 min — acrescente exemplos visuais de páginas conhecidas)
