# Roteiro de vídeo — Aula 9.6: Semântica

**Módulo 9 — HTML + CSS** · Duração alvo: ~5 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Escrever HTML semântico

## Termos técnicos a preparar antes
- **HTML semântico** — explicar: tags que dizem o que o conteúdo é.
- **header / nav / main / footer / article** — datilologia.
- Contraste com o uso genérico de **div**.

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** de boa prática + acessibilidade.
- **Enquadramento:** meio-corpo; genérico × semântico na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~35s
*Expressão: clara · Ritmo: lento*
- "HTML semântico usa tags que dizem o que o conteúdo é."
- "Não só como ele parece."

### 2. Genérico × semântico · ~60s
*Expressão: comparativa · Ritmo: lento · Corpo: um lado 'tudo igual', outro 'cada coisa nomeada'*
- `[MOSTRAR NA TELA: <div> para tudo (genérico) × <header> <nav> <main> <footer> <article> (semântico)]`
- "Usar div para tudo não diz nada sobre o conteúdo."
- "header, nav, main, footer, article dizem o que cada parte é."

### 3. Por que importa · ~60s
*Expressão: convincente · Ritmo: lento*
- "Por que isso importa?"
- "Acessibilidade: leitores de tela navegam por essas marcas."
- "Organização: o código conta a história da página."
- "Dica: antes de usar div, pergunte: existe uma tag que descreve isso?"
- "nav para menu. main para o conteúdo central."

### 4. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: tags semânticas descrevem o conteúdo e melhoram acessibilidade e organização."
- "Na próxima aula: o que é CSS."

**Soma estimada:** ~2m55s (alvo: ~5 min)
