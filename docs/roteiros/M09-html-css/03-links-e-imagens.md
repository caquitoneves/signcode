# Roteiro de vídeo — Aula 9.3: Links e imagens

**Módulo 9 — HTML + CSS** · Duração alvo: ~5 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Criar links e inserir imagens

## Termos técnicos a preparar antes
- **a (link) / href** — datilologia; leva a outra página.
- **img / src / alt** — datilologia; o alt é descrição para leitor de tela.
- Ênfase forte: acessibilidade do alt.

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** prático + ênfase em acessibilidade.
- **Enquadramento:** meio-corpo; as duas tags na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~30s
*Expressão: clara · Ritmo: lento*
- "Link leva a outra página."
- "Imagem mostra uma figura."
- "Duas tags essenciais."

### 2. Link · ~45s
*Expressão: didática · Ritmo: lento*
- `[MOSTRAR NA TELA: <a href="https://exemplo.com">Visite o site</a>]`
- "a, com href, mais o endereço."
- "O texto entre as tags é o que a pessoa clica."

### 3. Imagem e o alt · ~90s
*Expressão: enfática na acessibilidade · Ritmo: lento*
- `[MOSTRAR NA TELA: <img src="foto.jpg" alt="Descrição da foto" />]`
- "img, com src, mais o arquivo da imagem."
- "E alt, mais a descrição."
- "O alt descreve a imagem para quem usa leitor de tela. E dá contexto."
- "Regra importante: nunca deixe o alt vazio em imagens com significado."

### 4. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: a href cria links; img src alt mostra imagens."
- "O alt é essencial para acessibilidade."
- "Na próxima aula: listas."

**Soma estimada:** ~3m05s (alvo: ~5 min)
