# Roteiro de vídeo — Aula 9.8: Seletores e cores

**Módulo 9 — HTML + CSS** · Duração alvo: ~5m30s
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Usar seletores e definir cores

## Termos técnicos a preparar antes
- **Seletor** — por tag, por classe (.), por id (#).
- **Classe × id** — classe reutilizável; id único.
- **Cores:** nome, hex (#), rgb.

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** prático.
- **Enquadramento:** meio-corpo; os seletores e as cores na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~35s
*Expressão: clara · Ritmo: lento*
- "Um seletor escolhe o que estilizar."
- "A tag, uma classe, com ponto, ou um id, com cerquilha."

### 2. Seletores · ~70s
*Expressão: didática · Ritmo: lento · Corpo: três alvos*
- `[MOSTRAR NA TELA: p { } (toda tag p) · .destaque { } (class="destaque") · #topo { } (id="topo")]`
- "p sozinho: toda tag parágrafo."
- "ponto destaque: elementos com a classe destaque."
- "cerquilha topo: o elemento com id topo."

### 3. Cores · ~55s
*Expressão: didática · Ritmo: lento*
- `[MOSTRAR NA TELA: nome: red, blue, teal · hex: #4f46e5 · rgb: rgb(79,70,229)]`
- "Cores por nome: red, blue, teal."
- "Por hex: cerquilha, mais o código."
- "Por rgb: os três valores de vermelho, verde e azul."

### 4. Classe × id · ~40s
*Expressão: orientadora · Ritmo: lento*
- "Dica importante: classe, com ponto, é reutilizável em vários elementos."
- "id, com cerquilha, é único."
- "No dia a dia, use classes."

### 5. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: seletores escolhem o alvo — tag, ponto classe, cerquilha id."
- "Cores vêm por nome, hex ou rgb."
- "Na próxima aula: box model."

**Soma estimada:** ~3m40s (alvo: ~5m30s)
