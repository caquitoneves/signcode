# Roteiro de vídeo — Aula 9.1: Estrutura de uma página

**Módulo 9 — HTML + CSS** · Duração alvo: ~5m30s
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Reconhecer a estrutura base do HTML

## Termos técnicos a preparar antes
- **html / head / body** — datilologia; explique o papel de cada.
- **lang="pt-BR"** — ligação com acessibilidade (leitores de tela).

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** estruturador.
- **Enquadramento:** meio-corpo; o esqueleto HTML na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~35s
*Expressão: clara · Ritmo: lento*
- "Todo HTML segue o mesmo esqueleto."
- "html, head e body."

### 2. O esqueleto · ~90s
*Expressão: didática · Ritmo: lento · Corpo: aponte cada parte*
- `[MOSTRAR NA TELA: <!DOCTYPE html> <html lang="pt-BR"> <head> <title> </head> <body> <h1> </body> </html>]`
- "No topo, DOCTYPE html: avisa que é uma página."
- "html, com lang pt-br."
- "head: o cabeçalho, com o título da aba."
- "body: o corpo, o conteúdo visível."

### 3. Head × body · ~60s
*Expressão: comparativa · Ritmo: lento · Corpo: invisível × visível*
- `[MOSTRAR NA TELA: <head> título da aba, idioma, CSS (não aparece) · <body> tudo que a pessoa vê (aparece)]`
- "O head guarda dados: título da aba, idioma, links de CSS. Não aparece."
- "O body guarda tudo que a pessoa vê."
- "Dica: lang pt-br ajuda os leitores de tela e a acessibilidade. Importante desde a primeira linha."

### 4. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: head guarda dados da página; body guarda o conteúdo visível."
- "Na próxima aula: tags, títulos e parágrafos."

**Soma estimada:** ~3m25s (alvo: ~5m30s)
