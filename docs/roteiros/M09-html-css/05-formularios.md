# Roteiro de vídeo — Aula 9.5: Formulários

**Módulo 9 — HTML + CSS** · Duração alvo: ~5m30s
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Criar campos de formulário

## Termos técnicos a preparar antes
- **form / input / button / label** — datilologia.
- Regra de acessibilidade: todo input precisa de um label ligado (mesmo for/id).

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** prático + ênfase em acessibilidade.
- **Enquadramento:** meio-corpo; o formulário e a ligação label-input na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~35s
*Expressão: clara · Ritmo: lento*
- "Formulários coletam dados: nome, e-mail, mensagem."
- "A base de qualquer cadastro ou login."

### 2. Exemplo · ~70s
*Expressão: didática · Ritmo: lento*
- `[MOSTRAR NA TELA: <form> <label for="nome">Nome</label> <input id="nome" type="text" /> <button>Enviar</button> </form>]`
- "form agrupa tudo."
- "label com for nome: o rótulo do campo."
- "input com id nome: onde a pessoa digita."
- "button: o botão de enviar."

### 3. Acessibilidade primeiro · ~75s
*Expressão: enfática · Ritmo: lento · Corpo: ligue rótulo e campo com as mãos*
- `[MOSTRAR NA TELA: <label for="nome"> ⇄ <input id="nome"> — ligados pelo mesmo nome]`
- "O rótulo e o campo ficam ligados pelo mesmo nome."
- "O for do label é igual ao id do input."
- "Regra: todo input precisa de um label ligado."
- "Sem isso, quem usa leitor de tela não sabe o que preencher."

### 4. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: form agrupa; input recebe; label dá nome ao campo."
- "O label é essencial para acessibilidade."
- "Na próxima aula: semântica."

**Soma estimada:** ~3m20s (alvo: ~5m30s)

- [ ] Tela de apoio: formulário + ligação label-input
- [ ] Gesto de ligar rótulo e campo
