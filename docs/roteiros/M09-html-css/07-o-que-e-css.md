# Roteiro de vídeo — Aula 9.7: O que é CSS?

**Módulo 9 — HTML + CSS** · Duração alvo: ~5 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Entender o papel do CSS

## Termos técnicos a preparar antes
- **CSS** — datilologia; cuida do visual.
- **Regra de CSS: seletor / propriedade / valor** — mostre na tela.

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** animado (a página ganha cara).
- **Enquadramento:** meio-corpo; a regra de CSS na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~35s
*Expressão: animada · Ritmo: lento*
- "CSS cuida do visual."
- "Cores, tamanhos, espaços, layout."
- "O HTML dá o conteúdo; o CSS dá a aparência."

### 2. Como aplicar · ~45s
*Expressão: didática · Ritmo: lento*
- `[MOSTRAR NA TELA: <style> p { color: blue; } </style>]`
- "Dentro de style, você escreve as regras."
- "Aqui: todo parágrafo fica azul."

### 3. A regra de CSS · ~60s
*Expressão: didática · Ritmo: lento · Corpo: aponte as três partes*
- `[MOSTRAR NA TELA: p { color: blue; } → seletor · propriedade · valor]`
- "p é o seletor: o que vamos estilizar."
- "color é a propriedade."
- "blue é o valor."
- "Dica: mesma página, CSS diferente, visual totalmente diferente."
- "Conteúdo e aparência ficam separados de propósito."

### 4. Pergunta de fixação · ~30s
*Expressão: pergunta, depois confirmação*
- `[MOSTRAR NA TELA: "Para que serve o CSS?"]`
- "Para que serve o CSS?" *(pausa)*
- "Resposta: estilizar o visual da página."

### 5. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: CSS estiliza — escolhe um elemento, o seletor, e define propriedades."
- "Na próxima aula: seletores e cores."

**Soma estimada:** ~3m10s (alvo: ~5 min)
