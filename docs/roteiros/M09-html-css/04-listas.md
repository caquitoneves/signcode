# Roteiro de vídeo — Aula 9.4: Listas

**Módulo 9 — HTML + CSS** · Duração alvo: ~4m30s
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Criar listas com e sem ordem

## Termos técnicos a preparar antes
- **ul (sem ordem) / ol (numerada) / li (item)** — datilologia.
- Regra: ol quando a ordem importa; ul quando não.

## Visão geral de gravação
- **Ritmo geral:** ágil; aula curta.
- **Tom predominante:** prático.
- **Enquadramento:** meio-corpo; as duas listas na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~35s
*Expressão: clara · Ritmo: lento*
- "Duas listas em HTML."
- "u l: sem ordem, com bolinhas."
- "o l: numerada."
- "Cada item vai dentro de l i."

### 2. Exemplo · ~70s
*Expressão: didática · Ritmo: lento*
- `[MOSTRAR NA TELA: <ul><li>Café</li><li>Pão</li></ul> · <ol><li>Acordar</li><li>Estudar</li></ol>]`
- "A u l tem itens com bolinhas: café, pão."
- "A o l numera os itens: um, acordar; dois, estudar."
- "Dica: use o l quando a ordem importa, como numa receita. u l quando não."

### 3. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: u l é lista sem ordem; o l é numerada; l i é cada item."
- "Na próxima aula: formulários."

**Soma estimada:** ~2m05s (alvo: ~4m30s)
