# Roteiro de vídeo — Aula 9.11: Responsividade e acessibilidade visual

**Módulo 9 — HTML + CSS** · Duração alvo: ~5m30s
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Entender responsividade
- Aplicar acessibilidade visual

## Termos técnicos a preparar antes
- **Responsividade / @media** — datilologia; adaptar ao tamanho da tela.
- **Contraste** — texto legível sobre o fundo.
- Regra de ouro deste produto: nunca usar só a cor para dar um recado.

## Visão geral de gravação
- **Ritmo geral:** médio; aula com forte ligação ao propósito do produto.
- **Tom predominante:** de missão — "o visual é o canal principal".
- **Enquadramento:** meio-corpo; @media e a lista de acessibilidade na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~40s
*Expressão: firme, de propósito · Ritmo: lento*
- "A página precisa funcionar no celular e no desktop."
- "E ser legível para todos."
- "Isso não é extra. É parte do trabalho."

### 2. Responsividade · ~70s
*Expressão: didática · Ritmo: lento*
- `[MOSTRAR NA TELA: .grid { display: block; } @media (min-width: 768px) { .grid { display: flex; } }]`
- "Comece pelo celular: um layout simples, em blocos."
- "Para telas maiores, use @media."
- "Acima de certa largura, o layout vira flex."
- "Isso é responsividade: a página se adapta ao tamanho da tela."

### 3. Acessibilidade visual · ~90s
*Expressão: enfática, missão do produto · Ritmo: lento · Corpo: conte os pontos*
- `[MOSTRAR NA TELA: contraste suficiente · texto que cresce sem quebrar · nunca só a cor (some ícone ou texto)]`
- "Contraste suficiente entre o texto e o fundo."
- "Texto que cresce sem quebrar o layout."
- "E nunca usar só a cor para dar um recado."
- "Erro só em vermelho, por exemplo. Some um ícone ou um texto."
- "Dica: neste produto, feito para pessoas surdas, o visual é o canal principal."
- "Contraste, ícones e texto claro valem ouro."

### 4. Fechamento · ~25s
*Expressão: conclusiva, de propósito · Ritmo: lento*
- "Resumo: @media adapta a página ao tamanho da tela."
- "Contraste e sinais visuais, não só cor, garantem acessibilidade."
- "No próximo módulo: JavaScript no navegador."

**Soma estimada:** ~3m45s (alvo: ~5m30s)

- [ ] Tela de apoio: @media + lista de acessibilidade
