# Roteiro de vídeo — Aula 11.9: Publicando seu projeto na web

**Módulo 11 — Git e GitHub** · Duração alvo: ~7 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Publicar um site com GitHub Pages

## Termos técnicos a preparar antes
- **GitHub Pages** — datilologia; publica a página de graça, com link real.
- **Netlify / Vercel** — alternativas gratuitas. Datilologia.
- Ideia-chave: ter o projeto NO AR, não só o código.

## Visão geral de gravação
- **Ritmo geral:** médio; fecha o módulo com uma conquista.
- **Tom predominante:** empolgante ("seu site no ar!").
- **Enquadramento:** meio-corpo; o caminho e as alternativas na tela. Ideal: screencast do Settings → Pages.

## Roteiro (frase a frase)

### 1. Abertura · ~40s
*Expressão: empolgada · Ritmo: lento*
- "Mais do que o código: dá para colocar a página no ar."
- "Com um link que qualquer pessoa abre."
- "O caminho grátis é o GitHub Pages."

### 2. O caminho · ~70s
*Expressão: didática · Ritmo: lento*
- `[MOSTRAR NA TELA: repositório no GitHub → Settings → Pages → link público (usuario.github.io/projeto)]`
- "No repositório do GitHub, vá em Settings, depois Pages."
- "O GitHub gera um link público."
- "Algo como: seu usuário, ponto github ponto io, barra projeto."

### 3. Alternativas gratuitas · ~70s
*Expressão: 'tem outras opções' · Ritmo: lento · Corpo: liste as três*
- `[MOSTRAR NA TELA: GitHub Pages → HTML/CSS/JS simples · Netlify → sites estáticos, deploy automático · Vercel → front-end moderno]`
- "GitHub Pages: ótimo para páginas simples."
- "Netlify: sites estáticos, com deploy automático."
- "Vercel: projetos front-end modernos."

### 4. A grande diferença · ~50s
*Expressão: enfática, orgulhosa · Ritmo: lento*
- "Dica: ter o projeto no ar, não só o código, impressiona muito mais."
- "É a diferença entre 'escrevi um código'..."
- "...e 'fiz um site que funciona'."

### 5. Fechamento · ~25s
*Expressão: conclusiva, celebrativa · Ritmo: lento*
- "Resumo: o GitHub Pages, de graça, publica sua página com um link real."
- "Netlify e Vercel são alternativas."
- "No próximo módulo: o projeto final!"

**Soma estimada:** ~4m15s (alvo: ~7 min — ideal com screencast do Settings → Pages)
