# Roteiro de vídeo — Aula 11.1: O que é GitHub?

**Módulo 11 — Git e GitHub** · Duração alvo: ~5 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Diferenciar Git de GitHub

## Termos técnicos a preparar antes
- **GitHub** — datilologia; o site que hospeda o código na nuvem.
- Distinção central: Git (ferramenta local) × GitHub (site na nuvem).

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** esclarecedor + motivador (portfólio).
- **Enquadramento:** meio-corpo; Git × GitHub na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~35s
*Expressão: clara · Ritmo: lento*
- "GitHub é o site que hospeda seu código na nuvem."
- "Git é a ferramenta; GitHub é onde o código mora e é compartilhado."

### 2. A diferença · ~60s
*Expressão: comparativa · Ritmo: lento · Corpo: computador × nuvem*
- `[MOSTRAR NA TELA: Git → ferramenta no seu computador (o histórico) · GitHub → site na nuvem (guarda e compartilha)]`
- "Git: a ferramenta no seu computador. O histórico fica aí."
- "GitHub: o site na nuvem. Guarda e compartilha."

### 3. O portfólio · ~40s
*Expressão: motivadora · Ritmo: lento*
- "Dica importante: seu GitHub vira seu portfólio."
- "Recrutadores olham. Cada projeto publicado conta."

### 4. Pergunta de fixação · ~30s
*Expressão: pergunta, depois confirmação*
- `[MOSTRAR NA TELA: "Qual a diferença entre Git e GitHub?"]`
- "Qual a diferença entre Git e GitHub?" *(pausa)*
- "Resposta: Git é a ferramenta; GitHub é o site que hospeda o código."

### 5. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: Git é ferramenta local; GitHub é o serviço na nuvem que hospeda e compartilha."
- "Na próxima aula: criar um repositório."

**Soma estimada:** ~3m05s (alvo: ~5 min)
