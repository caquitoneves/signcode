# Roteiro de vídeo — Aula 11.5: Clonando um repositório

**Módulo 11 — Git e GitHub** · Duração alvo: ~5 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Clonar um repositório

## Termos técnicos a preparar antes
- **git clone** — datilologia; baixar um projeto existente com todo o histórico.
- Contraste: clone (baixar) × push (enviar).

## Visão geral de gravação
- **Ritmo geral:** ágil.
- **Tom predominante:** prático.
- **Enquadramento:** meio-corpo; clone × push na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~30s
*Expressão: clara · Ritmo: lento · Corpo: gesto de baixar (nuvem para baixo)*
- "git clone baixa um repositório do GitHub para o seu computador."
- "Com todo o histórico."

### 2. Clonando · ~45s
*Expressão: didática · Ritmo: lento*
- `[MOSTRAR NA TELA: git clone https://github.com/usuario/projeto.git]`
- "git clone, mais o endereço do repositório."
- "Pronto: o projeto inteiro no seu computador."

### 3. push × clone · ~50s
*Expressão: comparativa · Ritmo: lento · Corpo: baixar × enviar*
- `[MOSTRAR NA TELA: clone → GitHub para o computador (baixar) · push → computador para o GitHub (enviar)]`
- "clone baixa: do GitHub para o seu computador."
- "push envia: do seu computador para o GitHub."
- "Dica: clonar mantém a ligação com o GitHub."
- "Depois é só push e pull para sincronizar."

### 4. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: git clone, mais a URL, baixa um projeto existente com todo o histórico."
- "Na próxima aula: o README."

**Soma estimada:** ~2m25s (alvo: ~5 min)
