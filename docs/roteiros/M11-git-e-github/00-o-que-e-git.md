# Roteiro de vídeo — Aula 11.0: O que é Git?

**Módulo 11 — Git e GitHub** · Duração alvo: ~5 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Entender o papel do Git

## Termos técnicos a preparar antes
- **Git** — datilologia; guarda o histórico do código.
- **Commit / versão** — ponto no tempo salvo (aprofunda nas próximas aulas).
- Metáfora: "salvar com memória infinita; poder voltar no tempo".

## Visão geral de gravação
- **Ritmo geral:** médio; abre o módulo do portfólio.
- **Tom predominante:** libertador ("experimente sem medo").
- **Enquadramento:** meio-corpo; o contraste zip × histórico na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~40s
*Expressão: 'ferramenta que muda tudo' · Ritmo: lento*
- "Git guarda o histórico do seu código."
- "Cada versão salva, o que mudou e quando."
- "É como um 'salvar' com memória infinita."

### 2. Sem Git × com Git · ~70s
*Expressão: bem-humorada no 'zip', confiante no 'histórico' · Ritmo: lento · Corpo: bagunça × ordem*
- `[MOSTRAR NA TELA: projeto_final_v2_AGORA_VAI.zip (sem Git) × histórico limpo de commits, voltar no tempo (com Git)]`
- "Sem Git, a gente acaba com arquivos tipo 'projeto final versão dois agora vai, ponto zip'."
- "Com Git, um histórico limpo de versões, com poder de voltar no tempo."

### 3. Por que importa · ~40s
*Expressão: encorajadora · Ritmo: lento*
- "Dica: com Git você experimenta sem medo."
- "Se algo quebrar, dá para voltar a uma versão que funcionava."

### 4. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: Git registra o histórico do código e deixa você voltar a qualquer versão."
- "Na próxima aula: o que é GitHub."

**Soma estimada:** ~2m50s (alvo: ~5 min)
