# Roteiro de vídeo — Aula 11.4: Enviando para o GitHub — push

**Módulo 11 — Git e GitHub** · Duração alvo: ~5 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Usar git push

## Termos técnicos a preparar antes
- **git push** — datilologia; envia os commits do computador para o GitHub.
- Distinção: commit (local) × push (nuvem).

## Visão geral de gravação
- **Ritmo geral:** ágil; aula curta.
- **Tom predominante:** prático.
- **Enquadramento:** meio-corpo; o caminho computador → GitHub na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~30s
*Expressão: clara · Ritmo: lento · Corpo: gesto de enviar para cima (nuvem)*
- "git push envia seus commits do computador para o GitHub."
- "É o que deixa o código online."

### 2. O caminho · ~50s
*Expressão: didática · Ritmo: lento*
- `[MOSTRAR NA TELA: seu computador ──git push──▶ GitHub (nuvem) · git push]`
- "Do seu computador para o GitHub, com git push."

### 3. commit × push · ~45s
*Expressão: esclarecedora · Ritmo: lento · Corpo: local × nuvem*
- "Dica: faça commit com frequência, isso é local."
- "E push quando quiser publicar ou salvar na nuvem."
- "Um não substitui o outro."

### 4. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: commit salva local; push envia para o GitHub, deixando o código online."
- "Na próxima aula: clonar um repositório."

**Soma estimada:** ~2m25s (alvo: ~5 min — ideal com screencast)
