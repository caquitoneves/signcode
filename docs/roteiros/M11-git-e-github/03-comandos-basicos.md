# Roteiro de vídeo — Aula 11.3: Comandos básicos — add e commit

**Módulo 11 — Git e GitHub** · Duração alvo: ~6m30s
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Usar add e commit

## Termos técnicos a preparar antes
- **git add / git commit** — datilologia; selecionar e registrar.
- **working / staged / histórico** — as três fases. Mostre o fluxo.
- Metáfora: commit é uma foto do projeto.

## Visão geral de gravação
- **Ritmo geral:** médio; conceito de dois passos.
- **Tom predominante:** prático.
- **Enquadramento:** meio-corpo; o fluxo na tela. Ideal: screencast.

## Roteiro (frase a frase)

### 1. Abertura · ~35s
*Expressão: clara · Ritmo: lento · Corpo: dois passos*
- "Salvar no Git tem dois passos."
- "add: escolher o que entra."
- "commit: registrar a versão."

### 2. O fluxo · ~90s
*Expressão: didática · Ritmo: lento · Corpo: edita → add → commit*
- `[MOSTRAR NA TELA: você edita (working) → git add (staged) → git commit (histórico) → versão salva]`
- "Você edita os arquivos."
- "git add marca o que mudou."
- "git commit registra a versão, com uma mensagem."
- `[MOSTRAR NA TELA: git add . · git commit -m "feat: tela de login"]`
- "git add ponto marca tudo que mudou."
- "git commit menos m, mais a mensagem: registra."

### 3. A foto · ~55s
*Expressão: 'pense assim' · Ritmo: lento · Corpo: gesto de foto*
- "Dica: o commit é uma foto do projeto naquele momento."
- "A mensagem explica o que mudou."

### 4. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: git add seleciona, git commit menos m registra."
- "Juntos, salvam uma versão no histórico."
- "Na próxima aula: enviar para o GitHub com push."
