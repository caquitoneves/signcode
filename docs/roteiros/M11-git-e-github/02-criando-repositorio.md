# Roteiro de vídeo — Aula 11.2: Criando um repositório

**Módulo 11 — Git e GitHub** · Duração alvo: ~4m30s
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Iniciar um repositório

## Termos técnicos a preparar antes
- **Repositório (repo)** — datilologia; a pasta do projeto sob controle do Git.
- **git init / git status** — comandos. Ideal: mostrar no terminal.

## Visão geral de gravação
- **Ritmo geral:** ágil; aula curta e prática.
- **Tom predominante:** prático.
- **Enquadramento:** meio-corpo; comandos na tela. Ideal: screencast do terminal.

## Roteiro (frase a frase)

### 1. Abertura · ~30s
*Expressão: clara · Ritmo: lento*
- "Um repositório, ou repo, é a pasta do projeto sob controle do Git."

### 2. Começando · ~70s
*Expressão: didática · Ritmo: lento*
- `[MOSTRAR NA TELA: git init (vira repositório) · git status (mostra o que mudou)]`
- "git init transforma a pasta atual em repositório."
- "git status mostra o que mudou."
- "Dica: git init só precisa ser rodado uma vez por projeto."
- "Depois disso, a pasta já tem histórico."

### 3. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: git init cria o repositório; git status mostra o estado atual dos arquivos."
- "Na próxima aula: add e commit."

**Soma estimada:** ~2m00s (alvo: ~4m30s — ideal com screencast do terminal)
