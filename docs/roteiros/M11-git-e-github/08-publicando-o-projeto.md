# Roteiro de vídeo — Aula 11.8: Publicando o projeto

**Módulo 11 — Git e GitHub** · Duração alvo: ~5 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Publicar um repositório no GitHub

## Termos técnicos a preparar antes
- **Repositório público** — explicar: visível, com link para compartilhar.
- Reaproveite push e README.

## Visão geral de gravação
- **Ritmo geral:** ágil.
- **Tom predominante:** motivador (portfólio).
- **Enquadramento:** meio-corpo; os passos na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~30s
*Expressão: clara · Ritmo: lento*
- "Publicar é deixar seu repositório público no GitHub."
- "Com um link que dá para compartilhar."

### 2. Passos · ~70s
*Expressão: didática · Ritmo: lento · Corpo: três passos*
- `[MOSTRAR NA TELA: 1 criar repositório no GitHub · 2 git push do seu código · 3 repositório público → link]`
- "Um: criar o repositório no GitHub."
- "Dois: git push do seu código."
- "Três: deixar o repositório público. Agora tem um link para compartilhar."

### 3. Portfólio · ~40s
*Expressão: motivadora · Ritmo: lento*
- "Dica: um repositório público bem organizado, com README, é peça de portfólio."
- "Fixe os melhores no seu perfil."

### 4. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: repositório público, mais README, é igual a projeto compartilhável e peça de portfólio."
- "Na próxima aula: publicar seu projeto na web, no ar."

**Soma estimada:** ~2m40s (alvo: ~5 min)
