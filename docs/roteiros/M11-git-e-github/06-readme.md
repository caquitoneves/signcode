# Roteiro de vídeo — Aula 11.6: README

**Módulo 11 — Git e GitHub** · Duração alvo: ~5m30s
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Escrever um bom README

## Termos técnicos a preparar antes
- **README.md** — datilologia; a porta de entrada do projeto. É Markdown.
- Reaproveite a ideia de Markdown (títulos com #, listas).

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** 'isto te faz parecer profissional'.
- **Enquadramento:** meio-corpo; o que colocar e o exemplo na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~35s
*Expressão: clara · Ritmo: lento*
- "O README é a primeira coisa que alguém lê no seu repositório."
- "Explica o que é o projeto e como usá-lo."

### 2. O que colocar · ~70s
*Expressão: didática · Ritmo: lento · Corpo: conte os itens*
- `[MOSTRAR NA TELA: O que é · Como rodar · Tecnologias · Print ou link do projeto no ar]`
- "O que é o projeto, em uma frase."
- "Como rodar, em passos."
- "As tecnologias usadas."
- "E um print ou link do projeto no ar."

### 3. É Markdown · ~60s
*Expressão: 'você já conhece' · Ritmo: lento*
- `[MOSTRAR NA TELA: # Meu Projeto / Uma lista de tarefas... / ## Como rodar / 1. Abra o index.html]`
- "O README é Markdown."
- "Cerquilha para título. Lista para os passos."
- "Dica: um bom README faz seu projeto parecer profissional."
- "É o que o recrutador lê primeiro."

### 4. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: o README explica e vende o projeto."
- "É Markdown e vive na raiz do repositório."
- "Na próxima aula: commits bons."

**Soma estimada:** ~3m05s (alvo: ~5m30s)
