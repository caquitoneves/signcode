# Roteiro de vídeo — Aula 1.4: Navegador

**Módulo 1 — Como o Computador Funciona** · Duração alvo: ~5 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Entender o papel do navegador

## Termos técnicos a preparar antes
- **Navegador** — há sinal; use-o. Metáfora: "tradutor" e "palco".
- **HTML · CSS · JavaScript** — datilologia; associe estrutura / visual / comportamento.
- **Chrome · Edge · Firefox · Safari** — nomes próprios: datilologia.

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** esclarecedor; prepara o aluno para "seu site roda aqui".
- **Enquadramento:** meio-corpo; fluxo site → navegador → tela na lateral.

## Roteiro (frase a frase)

### 1. Abertura — o tradutor · ~40s
*Expressão: 'olha que interessante' · Ritmo: lento · Corpo: gesto de transformar (de um lado para o outro)*
- "O navegador é um tradutor."
- "Ele pega HTML, CSS e JavaScript."
- "E transforma tudo na página bonita que você vê."

### 2. O que o navegador faz · ~100s
*Expressão: didática · Ritmo: lento · Corpo: apresente os três arquivos, depois o navegador, depois a tela*
- "Um site tem três partes."
- `[MOSTRAR NA TELA: SITE = HTML (estrutura) + CSS (visual) + JavaScript (comportamento) → NAVEGADOR → TELA]`
- "HTML: a estrutura."
- "CSS: o visual."
- "JavaScript: o comportamento."
- "O navegador interpreta tudo isso."
- "E desenha a página na tela."

### 3. Exemplos e importância · ~60s
*Expressão: próxima, animada no 'seu palco' · Ritmo: médio*
- "Chrome, Edge, Firefox, Safari."
- "Todos fazem o mesmo trabalho básico."
- "E isto é importante para nós:"
- "O seu primeiro site vai rodar dentro do navegador."
- "Ele é o seu palco."

### 4. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: o navegador interpreta os arquivos da web e desenha a página."
- "Na próxima aula: a internet."

**Soma estimada:** ~3m40s (alvo: ~5 min)
