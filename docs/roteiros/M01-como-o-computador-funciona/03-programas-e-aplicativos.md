# Roteiro de vídeo — Aula 1.3: Programas e aplicativos

**Módulo 1 — Como o Computador Funciona** · Duração alvo: ~5 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Perceber que cada programa tem uma função

## Termos técnicos a preparar antes
- **Programa / aplicativo** — há sinais; use-os.
- **Chrome · VS Code · Git · Spotify** — nomes próprios: datilologia. (VS Code e Git voltam mais à frente.)

## Visão geral de gravação
- **Ritmo geral:** ágil; aula curta e leve.
- **Tom predominante:** cotidiano, com a analogia da cozinha.
- **Enquadramento:** meio-corpo.

## Roteiro (frase a frase)

### 1. Abertura — cada ferramenta, uma função · ~35s
*Expressão: leve · Ritmo: médio · Corpo: gesto de cortar (faca), de cozinhar (panela)*
- "Cada ferramenta tem uma função."
- "É como numa cozinha: a faca corta, a panela cozinha."
- "Com os programas é igual."

### 2. Ferramentas de quem programa · ~90s
*Expressão: apresentadora · Ritmo: médio, um por vez · Corpo: datilologia de cada nome + sua função*
- `[MOSTRAR NA TELA: Chrome → navegar · VS Code → escrever código · Git → controlar versões · Spotify → ouvir música]`
- "Chrome: para navegar na internet."
- "VS Code: para escrever código."
- "Git: para controlar as versões do projeto."
- "Spotify: para ouvir música."
- "Você vai conhecer o VS Code e o Git mais para frente."
- "São as ferramentas do dia a dia de quem programa."

### 3. Prática · ~40s
*Expressão: convite · Ritmo: lento*
- "Escolha três aplicativos que você usa todo dia."
- "Escreva a função de cada um."

### 4. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: software é feito de programas."
- "E cada programa resolve um tipo de tarefa."
- "Na próxima aula: o navegador."

**Soma estimada:** ~3m25s (alvo: ~5 min — amplie os exemplos se quiser)

## Checklist de gravação
- [ ] Datilologia dos nomes dos programas combinada
- [ ] Tela de apoio: lista programa → função
- [ ] Analogia da cozinha no início
