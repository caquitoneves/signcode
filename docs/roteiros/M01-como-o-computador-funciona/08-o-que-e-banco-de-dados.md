# Roteiro de vídeo — Aula 1.8: O que é banco de dados?

**Módulo 1 — Como o Computador Funciona** · Duração alvo: ~6 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Entender para que serve um banco de dados

## Termos técnicos a preparar antes
- **Banco de dados** — há sinal; use-o. Metáfora: "planilha turbinada".
- **Tabela / linha (registro) / coluna** — escolha sinais consistentes; mostre na tela.
- Ainda **sem SQL** — só o conceito.

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** concreto; conecta com o painel da própria plataforma.
- **Enquadramento:** meio-corpo; a tabela de exemplo na tela lateral.

## Roteiro (frase a frase)

### 1. Abertura — planilha turbinada · ~40s
*Expressão: 'imagine isto' · Ritmo: lento · Corpo: mãos desenhando uma grade*
- "Pense numa planilha turbinada."
- "O banco de dados guarda informações organizadas."
- "Para o programa consultar depois."

### 2. Como os dados ficam organizados · ~100s
*Expressão: didática · Ritmo: lento · Corpo: aponte linha e coluna separadamente*
- `[MOSTRAR NA TELA: tabela USUÁRIOS — colunas ID, Nome, Email; linhas Ana, João]`
- "Veja uma tabela de usuários."
- "Cada linha é um registro. Por exemplo, a Ana."
- "Cada coluna é um tipo de informação. Por exemplo, o email."

### 3. Prática · ~70s
*Expressão: convite, conexão com o curso · Ritmo: lento*
- "Pense nesta plataforma de cursos."
- "Quais informações ela precisaria guardar?"
- "Uma resposta possível: nome, email, curso, progresso, aulas concluídas."
- "Repare: são as mesmas coisas que você vê no seu painel."

### 4. Pergunta de fixação · ~30s
*Expressão: pergunta, depois confirmação*
- `[MOSTRAR NA TELA: "Para que serve um banco de dados?"]`
- "Para que serve um banco de dados?" *(pausa)*
- "Resposta: para armazenar e organizar informações."

### 5. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: banco de dados serve para armazenar e organizar informações."
- "Na próxima aula: revisão de tudo que vimos."

**Soma estimada:** ~4m20s (alvo: ~6 min)
