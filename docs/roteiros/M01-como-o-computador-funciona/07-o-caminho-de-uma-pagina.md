# Roteiro de vídeo — Aula 1.7: O caminho de uma página

**Módulo 1 — Como o Computador Funciona** · Duração alvo: ~7 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Descrever o caminho de uma requisição web

## Termos técnicos a preparar antes
- **Navegador · internet · servidor · banco de dados** — todos já vistos; mantenha os mesmos sinais.
- Reforce o par **requisição / resposta** (ida e volta).

## Visão geral de gravação
- **Ritmo geral:** lento; é uma aula de síntese ("juntando tudo").
- **Tom predominante:** narrativo — conte como uma viagem em câmera lenta.
- **Enquadramento:** meio-corpo; o diagrama de ida e volta é o centro da aula.

## Roteiro (frase a frase)

### 1. Abertura · ~40s
*Expressão: 'prepare-se, é rápido' · Ritmo: lento · Corpo: gesto de 'câmera lenta'*
- "Tudo isto acontece em menos de um segundo."
- "Acontece quando você abre uma rede social."
- "Vamos ver em câmera lenta."

### 2. A viagem de ida · ~110s
*Expressão: narrativa, acompanhando o movimento · Ritmo: lento, um passo por vez · Corpo: desça pelo espaço, de cima para baixo*
- `[MOSTRAR NA TELA: Você → Navegador → Internet → Servidor → Banco de dados]`
- "Você clica ou digita o endereço."
- "O navegador envia o pedido."
- "O pedido viaja pela internet."
- "Chega ao servidor."
- "O servidor pode precisar de dados."
- "Então ele consulta o banco de dados."

### 3. A viagem de volta · ~100s
*Expressão: narrativa, agora subindo · Ritmo: lento · Corpo: suba pelo espaço, de baixo para cima*
- `[MOSTRAR NA TELA: Banco de dados → Servidor → Internet → Navegador → Tela: página pronta!]`
- "O banco devolve os dados."
- "O servidor monta a resposta."
- "A resposta volta pela internet."
- "Chega ao navegador."
- "E a página aparece na tela, pronta."

### 4. Prática · ~45s
*Expressão: convite · Ritmo: lento*
- "Agora é com você."
- "Explique, com suas palavras, essa viagem."
- "Imagine que você está abrindo uma rede social."

### 5. Fechamento · ~25s
*Expressão: conclusiva, satisfeita · Ritmo: lento*
- "Resumo: uma página é uma viagem de ida e volta."
- "Pedido, servidor, talvez o banco, resposta, tela."
- "Na próxima aula: o que é um banco de dados."

**Soma estimada:** ~5m20s (alvo: ~7 min — pode repetir a viagem inteira uma vez para fixar)

## Checklist de gravação
- [ ] Tela de apoio: diagrama completo de ida e volta
- [ ] Usar o espaço de sinalização para representar o movimento (desce / sobe)
- [ ] Ritmo bem lento — é síntese de todo o módulo
