# Roteiro de vídeo — Aula 7.1: Criando uma função

**Módulo 7 — Funções** · Duração alvo: ~5m30s
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Declarar uma função
- Chamar (executar) uma função

## Termos técnicos a preparar antes
- **function** — datilologia; a palavra que declara.
- **Declarar × chamar** — dois momentos distintos. Sinais/gestos diferentes.
- **nome()** — chamar: executar a função.

## Visão geral de gravação
- **Ritmo geral:** lento; separa bem declarar de chamar.
- **Tom predominante:** fundamental.
- **Enquadramento:** meio-corpo; a anatomia da função na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~35s
*Expressão: clara · Ritmo: lento · Corpo: dois gestos — escrever / mandar executar*
- "Uma função tem duas partes."
- "Você declara: escreve a receita."
- "E depois chama: manda executar."

### 2. Declarar e chamar · ~85s
*Expressão: didática · Ritmo: lento*
- `[MOSTRAR NA TELA: function saudar() { console.log("Olá!"); } → saudar(); → saudar();]`
- "function saudar, abre chaves: mostra Olá. Isso declara."
- "saudar, abre e fecha parênteses: isso chama. Mostra Olá."
- "Chamei duas vezes, mostrou duas vezes."

### 3. Anatomia · ~60s
*Expressão: didática · Ritmo: lento · Corpo: aponte cada parte*
- `[MOSTRAR NA TELA: function (palavra) · saudar (nome) · () (parâmetros) · { } (corpo)]`
- "function é a palavra."
- "saudar é o nome."
- "Os parênteses guardam os parâmetros."
- "As chaves guardam o corpo."
- "Dica: declarar não executa. A função só roda quando você chama, com nome e parênteses."

### 4. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: function nome, chaves, declara. nome, parênteses, executa."
- "Na próxima aula: parâmetros."
