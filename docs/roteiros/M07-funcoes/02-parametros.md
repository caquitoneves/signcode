# Roteiro de vídeo — Aula 7.2: Parâmetros

**Módulo 7 — Funções** · Duração alvo: ~5m30s
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Usar parâmetros
- Passar argumentos ao chamar

## Termos técnicos a preparar antes
- **Parâmetro** — a entrada declarada (na receita).
- **Argumento** — o valor real passado ao chamar.
- Esta aula tem desafio de código (m7-saudar).

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** didático; distinção parâmetro × argumento.
- **Enquadramento:** meio-corpo; exemplo e a distinção na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~30s
*Expressão: clara · Ritmo: lento*
- "Parâmetros são as entradas da função."
- "O que ela recebe para trabalhar."

### 2. Exemplo · ~70s
*Expressão: didática · Ritmo: lento*
- `[MOSTRAR NA TELA: function saudar(nome) { console.log("Olá, " + nome + "!"); } → saudar("Ana") → Olá, Ana!]`
- "function saudar, parênteses nome. nome é o parâmetro."
- "Dentro: mostra Olá, mais nome."
- "saudar de Ana: Olá, Ana. saudar de Caio: Olá, Caio."

### 3. Parâmetro × argumento · ~70s
*Expressão: 'veja a diferença' · Ritmo: lento · Corpo: receita × valor real*
- `[MOSTRAR NA TELA: saudar(nome) → nome = parâmetro (na receita) · saudar("Ana") → "Ana" = argumento (valor real)]`
- "Na declaração, nome é o parâmetro. Faz parte da receita."
- "Na chamada, Ana é o argumento. É o valor real que você passa."

### 4. Desafio de código · ~75s
*Expressão: incentivadora · Ritmo: lento*
- `[MOSTRAR NA TELA: desafio m7-saudar — saudar(nome) retorna "Olá, NOME!"]`
- "No desafio: crie a função saudar, com parâmetro nome."
- "Ela retorna a frase Olá, nome, exclamação."
- "Por exemplo, saudar de Ana devolve 'Olá, Ana!'."
- "Atenção: aqui é retornar, com return, não só mostrar."

### 5. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: parâmetro é a entrada declarada; argumento é o valor que você passa."
- "Na próxima aula: retorno."
