# Roteiro de vídeo — Aula 7.3: Retorno

**Módulo 7 — Funções** · Duração alvo: ~6m30s
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Usar return
- Guardar o resultado de uma função

## Termos técnicos a preparar antes
- **return** — datilologia + explicar: devolver um valor a quem chamou.
- Distinção central: **mostrar** (console.log) × **devolver** (return).
- Esta aula tem desafio de código (m7-retorno).

## Visão geral de gravação
- **Ritmo geral:** lento; mostrar × devolver confunde muito.
- **Tom predominante:** cuidadoso, com contraste claro.
- **Enquadramento:** meio-corpo; os dois exemplos lado a lado.

## Roteiro (frase a frase)

### 1. Abertura · ~40s
*Expressão: clara · Ritmo: lento · Corpo: gesto de 'entregar'*
- "return faz a função devolver um valor para quem a chamou."
- "Sem return, a função só executa e não entrega nada."

### 2. Mostrar × devolver · ~100s
*Expressão: comparativa · Ritmo: lento · Corpo: um lado 'mostra', outro 'entrega'*
- `[MOSTRAR NA TELA: function dobroLog(n) { console.log(n*2); } (só mostra) × function dobro(n) { return n*2; } (devolve)]`
- "A primeira só mostra na tela. O valor some depois."
- "A segunda devolve o valor. Dá para guardar e usar."
- `[MOSTRAR NA TELA: const x = dobro(5); → x vale 10 → console.log(x + 1) → 11]`
- "x recebe dobro de cinco: dez."
- "Dá para usar o resultado: x mais um dá onze."

### 3. Cuidado com o que vem depois · ~45s
*Expressão: alerta · Ritmo: lento*
- "Cuidado: depois do return, a função para."
- "Nada abaixo dele roda."

### 4. Desafio de código · ~75s
*Expressão: incentivadora · Ritmo: lento*
- `[MOSTRAR NA TELA: desafio m7-retorno — dobro(n) retorna n * 2]`
- "No desafio: crie a função dobro, com parâmetro n."
- "Ela retorna o número multiplicado por dois."
- "dobro de cinco é dez. dobro de zero é zero."

### 5. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: return entrega um valor. Use quando quiser aproveitar o resultado depois."
- "Na próxima aula: funções e responsabilidades."
