# Roteiro de vídeo — Aula 7.5: Arrow functions

**Módulo 7 — Funções** · Duração alvo: ~5m30s
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Escrever arrow functions

## Termos técnicos a preparar antes
- **Arrow function** — explicar: forma curta de escrever função; a "seta" => .
- Regra: uma linha já devolve sem return; com { } precisa de return.
- Esta aula tem desafio de código (m7-triplo).

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** 'versão enxuta', comum no dia a dia.
- **Enquadramento:** meio-corpo; tradicional × arrow na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~30s
*Expressão: clara · Ritmo: lento · Corpo: gesto de seta*
- "Arrow function é uma forma mais curta de escrever funções."
- "Muito comum no dia a dia."

### 2. Mesma função, duas formas · ~80s
*Expressão: comparativa · Ritmo: lento · Corpo: forma longa × forma curta*
- `[MOSTRAR NA TELA: function dobro(n) { return n*2; } × const dobro = (n) => n * 2;]`
- "Na forma tradicional: function dobro, return n vezes dois."
- "Na arrow, a mesma coisa: const dobro recebe, parênteses n, seta, n vezes dois."

### 3. A seta · ~55s
*Expressão: didática · Ritmo: lento · Corpo: aponte entrada, seta, saída*
- `[MOSTRAR NA TELA: (n) => n * 2 → entrada · seta · o que devolve]`
- "Parênteses n: a entrada."
- "A seta: igual, maior."
- "Depois da seta: o que a função devolve."
- "Dica: com uma linha, a arrow já devolve sem return."
- "Com chaves, você precisa do return."

### 4. Desafio de código · ~70s
*Expressão: incentivadora · Ritmo: lento*
- `[MOSTRAR NA TELA: desafio m7-triplo — arrow triplo(n) retorna n * 3]`
- "No desafio: usando uma arrow function, crie triplo."
- "Ela recebe n e retorna n vezes três."
- "triplo de quatro é doze."

### 5. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: const f recebe, parênteses x, seta, é a versão curta."
- "Muito usada em métodos de array, no próximo módulo."
- "Na próxima aula: boas práticas de funções."
