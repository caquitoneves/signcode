## Objetivo da aula
- Combinar condições com && || !

## Termos técnicos a preparar antes
- **&& (E) · || (OU) · ! (NÃO)** — defina um sinal/gesto para cada. São o foco da aula.
- Ideia: && é exigente (tudo verdadeiro); || é tranquilo (um basta); ! inverte.

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** didático com a "tabela-verdade".
- **Enquadramento:** meio-corpo; a tabela-verdade na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~35s
*Expressão: clara · Ritmo: lento · Corpo: gesto de juntar*
- "Para juntar perguntas numa decisão, usamos três operadores."
- "E, OU, e NÃO."

### 2. O que cada um faz · ~80s
*Expressão: didática · Ritmo: lento · Corpo: gesto distinto para cada*
- `[MOSTRAR NA TELA: && (E) tudo verdadeiro · || (OU) pelo menos um · ! (NÃO) inverte]`
- "E, dois e-comerciais: verdadeiro só se os dois lados forem verdadeiros."
- "OU, duas barras: verdadeiro se pelo menos um lado for verdadeiro."
- "NÃO, exclamação: inverte, vira o contrário."

### 3. Exemplo e tabela-verdade · ~80s
*Expressão: 'veja os resultados' · Ritmo: lento · Corpo: aponte cada combinação*
- `[MOSTRAR NA TELA: idade >= 18 && temIngresso → true]`
- "Idade maior ou igual a dezoito E tem ingresso: true."
- `[MOSTRAR NA TELA: true && true → true · true && false → false · true || false → true · !true → false]`
- "Verdadeiro E verdadeiro: verdadeiro."
- "Verdadeiro E falso: falso."
- "Verdadeiro OU falso: verdadeiro."
- "NÃO verdadeiro: falso."
- "Dica: E é exigente, quer tudo. OU é tranquilo, um já basta."

### 4. Pergunta de fixação · ~30s
*Expressão: pergunta, depois confirmação*
- `[MOSTRAR NA TELA: "Quando a && b é verdadeiro?"]`
- "Quando a E b é verdadeiro?" *(pausa)*
- "Resposta: quando os dois são verdadeiros."

### 5. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: E, OU e NÃO combinam perguntas em uma decisão só."
- "Na próxima aula: a decisão if."
