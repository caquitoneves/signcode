# Roteiro de vídeo — Aula 5.4: O else

**Módulo 5 — Operadores e Decisões** · Duração alvo: ~5m30s
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Usar if/else

## Termos técnicos a preparar antes
- **else** — datilologia + reaproveite o sinal de "senão" do Módulo 2.
- Ideia: sempre cai em um dos dois caminhos; nunca os dois, nunca nenhum.
- Esta aula tem desafio de código (m5-else).

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** complementar ao if.
- **Enquadramento:** meio-corpo; os dois caminhos em lados opostos.

## Roteiro (frase a frase)

### 1. Abertura · ~30s
*Expressão: clara · Ritmo: lento · Corpo: sinal de 'senão'*
- "else quer dizer 'senão'."
- "É o outro caminho, quando o if é falso."

### 2. A estrutura · ~55s
*Expressão: didática · Ritmo: lento · Corpo: caminho A de um lado, B do outro*
- `[MOSTRAR NA TELA: if (condição) { caminho A } else { caminho B }]`
- "Se a condição for verdadeira: caminho A."
- "Senão: caminho B."

### 3. Exemplo · ~55s
*Expressão: concreta · Ritmo: lento*
- `[MOSTRAR NA TELA: const idade = 15; if (idade >= 18) { "Maior" } else { "Menor" }]`
- "idade recebe quinze."
- "Se maior ou igual a dezoito: 'Maior'. Senão: 'Menor'."
- "Como quinze é menor que dezoito, roda o else: 'Menor'."

### 4. Sempre um dos dois · ~45s
*Expressão: enfática · Ritmo: lento · Corpo: bifurcação*
- `[MOSTRAR NA TELA: condição? → true: if · false: else]`
- "Um dos dois blocos sempre roda."
- "Nunca os dois. Nunca nenhum."

### 5. Desafio de código · ~70s
*Expressão: incentivadora · Ritmo: lento*
- `[MOSTRAR NA TELA: desafio m5-else — nota vale 7; "Aprovado" se >= 6, senão "Reprovado"]`
- "No desafio: a nota já vale sete."
- "Guarde em resultado o texto 'Aprovado' se a nota for maior ou igual a seis."
- "Senão, 'Reprovado'."

### 6. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: else cobre o caso em que o if é falso."
- "Sempre cai em um dos dois caminhos."
- "Na próxima aula: o else if."
