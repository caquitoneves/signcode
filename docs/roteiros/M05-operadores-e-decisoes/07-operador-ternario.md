## Objetivo da aula
- Usar o operador ternário
- Saber quando preferir if/else

## Termos técnicos a preparar antes
- **Operador ternário** — explicar: if/else curto, em uma linha, que devolve um valor.
- Forma: condição ? valorSeVerdadeiro : valorSeFalso.
- Esta aula tem desafio de código (m5-ternario).

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** 'atalho útil', com ressalva de legibilidade.
- **Enquadramento:** meio-corpo; comparação if/else × ternário na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~35s
*Expressão: 'um atalho' · Ritmo: lento*
- "O ternário é um if/else curtinho, em uma linha."
- "E ele devolve um valor."

### 2. A forma · ~45s
*Expressão: didática · Ritmo: lento · Corpo: aponte as três partes*
- `[MOSTRAR NA TELA: condição ? valorSeVerdadeiro : valorSeFalso]`
- "A condição, interrogação."
- "O valor se for verdadeiro, dois-pontos, o valor se for falso."

### 3. if/else × ternário · ~80s
*Expressão: comparativa · Ritmo: lento · Corpo: lado longo × lado curto*
- `[MOSTRAR NA TELA: if/else (4 linhas) × const status = idade >= 18 ? "Maior" : "Menor"]`
- "Com if/else, são várias linhas para escolher o status."
- "Com ternário, uma linha só: idade maior ou igual a dezoito, interrogação, 'Maior', dois-pontos, 'Menor'."
- "Mesma ideia, mais curto."
- "Dica: use o ternário para escolher um valor."
- "Para rodar vários comandos, prefira o if/else normal. Fica mais legível."

### 4. Desafio de código · ~70s
*Expressão: incentivadora · Ritmo: lento*
- `[MOSTRAR NA TELA: desafio m5-ternario — idade vale 20; status "Maior" se >=18, senão "Menor", com ternário]`
- "No desafio: a idade já vale vinte."
- "Usando o ternário, guarde em status 'Maior' se idade maior ou igual a dezoito."
- "Senão, 'Menor'."

### 5. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: ternário é condição, interrogação, a, dois-pontos, b."
- "Ótimo para escolher um valor."
