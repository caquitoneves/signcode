# Roteiro de vídeo — Aula 5.3: A decisão if

**Módulo 5 — Operadores e Decisões** · Duração alvo: ~5m30s
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Escrever um if
- Entender como a condição é avaliada

## Termos técnicos a preparar antes
- **if** — datilologia + reaproveite o sinal de "se" do Módulo 2.
- **Bloco { }** — explicar: o que roda quando a condição é verdadeira.
- Esta aula tem desafio de código (m5-if).

## Visão geral de gravação
- **Ritmo geral:** lento; é a primeira estrutura de decisão em código.
- **Tom predominante:** fundamental.
- **Enquadramento:** meio-corpo; estrutura e exemplo na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~30s
*Expressão: clara · Ritmo: lento · Corpo: sinal de 'se'*
- "if quer dizer 'se'."
- "O bloco entre chaves só roda quando a condição é verdadeira."

### 2. A estrutura · ~60s
*Expressão: didática · Ritmo: lento · Corpo: aponte a condição e o bloco*
- `[MOSTRAR NA TELA: if ( condição ) { // roda só se for true }]`
- "if, abre parênteses, a condição, fecha parênteses."
- "Abre chaves: o código que roda só se for verdadeiro."

### 3. Exemplo · ~55s
*Expressão: concreta · Ritmo: lento*
- `[MOSTRAR NA TELA: const idade = 20; if (idade >= 18) { console.log("Maior de idade"); }]`
- "idade recebe vinte."
- "Se idade maior ou igual a dezoito: mostrar 'Maior de idade'."
- "Como vinte é maior que dezoito, o bloco roda."

### 4. Como o computador lê · ~50s
*Expressão: didática · Ritmo: lento · Corpo: bifurcação true/false*
- `[MOSTRAR NA TELA: idade >= 18? → true: roda o bloco · false: pula o bloco]`
- "A condição vira um booleano."
- "Se true, entra no bloco. Se false, pula."

### 5. Desafio de código · ~70s
*Expressão: incentivadora · Ritmo: lento*
- `[MOSTRAR NA TELA: desafio m5-if — temperatura vale 35; se > 30, estaQuente = true]`
- "No desafio: a temperatura já vale trinta e cinco."
- "Se a temperatura for maior que trinta, guarde true em estaQuente."
- "Escreva o if."

### 6. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: if abre parênteses condição, abre chaves: roda só quando é verdadeiro."
- "Na próxima aula: o else."
