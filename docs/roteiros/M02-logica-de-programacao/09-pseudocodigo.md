# Roteiro de vídeo — Aula 2.9: Pseudocódigo

**Módulo 2 — Lógica de Programação** · Duração alvo: ~6 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Escrever soluções em pseudocódigo

## Termos técnicos a preparar antes
- **Pseudocódigo** — datilologia + explicar: "quase código, em linguagem humana". A ponte entre a ideia e o código real.
- **INÍCIO / FIM / SE / SENÃO** — reaproveite os sinais de decisão já vistos.

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** de rascunho — "sem regras rígidas, só clareza".
- **Enquadramento:** meio-corpo; o exemplo de pseudocódigo na tela.

## Roteiro (frase a frase)

### 1. Abertura — a ponte · ~40s
*Expressão: 'quase lá' · Ritmo: lento · Corpo: gesto de ponte entre dois pontos*
- "O pseudocódigo é uma ponte."
- "Uma ponte entre a ideia e o código."
- "Você escreve quase como fala, mas já com estrutura."

### 2. Exemplo · ~90s
*Expressão: didática · Ritmo: lento · Corpo: siga as linhas de cima para baixo*
- `[MOSTRAR NA TELA: INÍCIO → pedir a idade → SE idade >= 18: "maior de idade" → SENÃO: "menor de idade" → FIM]`
- "Início."
- "Pedir a idade."
- "Se a idade for maior ou igual a dezoito: mostrar 'maior de idade'."
- "Senão: mostrar 'menor de idade'."
- "Fim."

### 3. Por que usar? · ~70s
*Expressão: convincente · Ritmo: médio · Corpo: conte os motivos*
- "Por que usar pseudocódigo?"
- "Você organiza a lógica sem se preocupar com as regras de uma linguagem."
- "Fica fácil revisar antes de programar."
- "E serve para qualquer linguagem depois."
- "Dica: não existe regra fixa."
- "O importante é ficar claro para um humano ler."

### 4. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: pseudocódigo é o rascunho da solução em linguagem quase humana."
- "Na próxima aula: decomposição de problemas."
