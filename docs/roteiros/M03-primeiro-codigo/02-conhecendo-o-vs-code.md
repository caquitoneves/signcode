# Roteiro de vídeo — Aula 3.2: Conhecendo o VS Code

**Módulo 3 — Primeiro Código** · Duração alvo: ~5 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Reconhecer as áreas principais do VS Code

## Termos técnicos a preparar antes
- **VS Code** — datilologia.
- **Explorador de arquivos · Editor · Terminal** — as três áreas. Sinais/posições consistentes.

## Visão geral de gravação
- **Ritmo geral:** médio; visita guiada.
- **Tom predominante:** acolhedor — "comece simples".
- **Enquadramento:** meio-corpo; o mapa da tela do VS Code ao lado. Ideal: screencast real do editor.

## Roteiro (frase a frase)

### 1. Abertura · ~30s
*Expressão: convidativa · Ritmo: lento*
- "O VS Code é gratuito."
- "É onde a maior parte dos programadores escreve código."
- "Vamos conhecer o essencial."

### 2. O mapa da tela · ~100s
*Expressão: guia de tour · Ritmo: lento · Corpo: aponte cada região na tela (esquerda, centro, baixo)*
- `[MOSTRAR NA TELA: layout do VS Code — Explorador (esquerda) · Editor (centro) · Terminal (baixo)]`
- "À esquerda: o explorador de arquivos. Os arquivos do seu projeto."
- "No centro: o editor. Onde você digita o código."
- "Embaixo: o terminal. Onde você dá comandos."
- "Dica: comece simples."
- "Extensões ajudam, mas o editor puro já basta nas primeiras semanas."

### 3. Fechamento · ~25s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: o VS Code é o seu espaço de trabalho."
- "Arquivos à esquerda, código no centro, terminal embaixo."
- "Na próxima aula: o terminal, sem medo."

**Soma estimada:** ~2m35s (alvo: ~5 min — ideal gravar com um screencast real do VS Code)
