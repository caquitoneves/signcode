# Roteiro de vídeo — Aula 3.0: O que é JavaScript?

**Módulo 3 — Primeiro Código** · Duração alvo: ~5 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Saber o que é JavaScript e por que vamos usá-lo

## Termos técnicos a preparar antes
- **JavaScript (JS)** — datilologia; é a linguagem do curso.
- **Código / programação** — mantenha os sinais já usados.
- **HTML / CSS** — datilologia (voltam nos Módulos 9 e 10).

## Visão geral de gravação
- **Ritmo geral:** médio; momento de virada ("código de verdade").
- **Tom predominante:** empolgante, de novo começo.
- **Enquadramento:** meio-corpo; tabela de vantagens e o fluxo na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~40s
*Expressão: empolgada, marco importante · Ritmo: lento*
- "Chegou a hora de escrever código de verdade."
- "A partir daqui, você programa em JavaScript."
- "E vê o resultado na hora."

### 2. Por que JavaScript? · ~90s
*Expressão: convincente · Ritmo: médio · Corpo: aponte cada vantagem*
- `[MOSTRAR NA TELA: Roda no navegador · Vira algo visual rápido · Conversa com HTML e CSS]`
- "Roda no navegador. Você não precisa instalar nada para começar."
- "Vira algo visual rápido. Da lógica ao primeiro projeto em pouco tempo."
- "Conversa com HTML e CSS. É a base para criar sites."

### 3. Onde ela vive · ~60s
*Expressão: didática · Ritmo: lento · Corpo: siga o fluxo de cima para baixo*
- `[MOSTRAR NA TELA: Você escreve JavaScript → o navegador executa → a página ganha vida]`
- "Você escreve JavaScript."
- "O navegador executa."
- "E a página ganha vida: botões, listas, cálculos."
- "Dica: aqui na plataforma você já roda JavaScript no editor da própria aula. Sem configurar nada."

### 4. Fechamento · ~25s
*Expressão: conclusiva, animada · Ritmo: lento*
- "Resumo: JavaScript é a linguagem que dá comportamento às páginas."
- "É onde a sua programação começa a virar produto."
- "Na próxima aula: preparar o seu ambiente."

**Soma estimada:** ~3m35s (alvo: ~5 min)
