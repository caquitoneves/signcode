# Roteiro de vídeo — Aula 3.3: Conhecendo o terminal

**Módulo 3 — Primeiro Código** · Duração alvo: ~6 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Entender o que é o terminal e alguns comandos básicos

## Termos técnicos a preparar antes
- **Terminal** — datilologia + explicar: janela onde você conversa com o computador por texto.
- **Comando** — sinal consistente.
- **node --version · ls · cd** — mostre na tela; explique cada um com calma.

## Visão geral de gravação
- **Ritmo geral:** lento; desarmar o medo do terminal.
- **Tom predominante:** tranquilizador.
- **Enquadramento:** meio-corpo; os comandos na tela. Ideal: screencast do terminal.

## Roteiro (frase a frase)

### 1. Abertura — calma · ~35s
*Expressão: tranquilizadora · Ritmo: lento · Corpo: gesto de 'calma'*
- "Calma com o terminal."
- "Ele parece assustador."
- "Mas no começo você usa pouquíssimos comandos."

### 2. O que é · ~45s
*Expressão: didática · Ritmo: lento*
- "O terminal é uma janela."
- "Você conversa com o computador por texto, digitando comandos."

### 3. Comandos que você verá · ~90s
*Expressão: 'veja estes três' · Ritmo: lento, um por vez · Corpo: aponte cada comando*
- `[MOSTRAR NA TELA: node --version · ls (dir no Windows) · cd minha-pasta]`
- "node espaço menos menos version: mostra a versão do Node."
- "l s: lista os arquivos da pasta. No Windows, é dir."
- "c d, mais o nome: entra em uma pasta."

### 4. Tranquilizar · ~40s
*Expressão: acolhedora · Ritmo: médio*
- "No começo, quase tudo dá para fazer pelo VS Code e pelo navegador."
- "O terminal entra aos poucos, quando você usar o Git."

### 5. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: terminal é dar comandos por texto."
- "Poucos comandos já resolvem muita coisa."
- "Na próxima aula: seu primeiro programa!"

**Soma estimada:** ~3m50s (alvo: ~6 min — ideal com screencast do terminal)
