# Roteiro de vídeo — Aula 3.1: Preparando seu ambiente

## Objetivo da aula
- Saber o mínimo necessário para programar no seu computador

## Termos técnicos a preparar antes
- **Editor de código / VS Code** — datilologia; o lugar de escrever código.
- **Node.js** — datilologia; explicar: rodar JavaScript fora do navegador (opcional agora).

## Visão geral de gravação
- **Ritmo geral:** médio; tranquilizar sobre instalação.
- **Tom predominante:** prático e sem pressão.
- **Enquadramento:** meio-corpo; o "kit mínimo" na tela.

## Roteiro (frase a frase)

### 1. Abertura — o objetivo · ~35s
*Expressão: clara · Ritmo: lento*
- "Objetivo desta aula:"
- "Sair daqui sabendo exatamente onde escrever código."
- "Para quando você quiser programar fora da plataforma."

### 2. O kit mínimo · ~75s
*Expressão: organizadora · Ritmo: lento · Corpo: conte os três itens*
- `[MOSTRAR NA TELA: Editor (VS Code, grátis) · Navegador (você já tem) · Node.js (opcional)]`
- "Um editor de código: o VS Code, que é grátis."
- "Um navegador: você já tem."
- "Node.js, opcional, para rodar JavaScript fora do navegador."

### 3. Dois caminhos · ~90s
*Expressão: 'escolha conforme o momento' · Ritmo: médio · Corpo: dois lados no espaço*
- "Você tem dois caminhos."
- "Agora, aprendendo: use o editor embutido de cada aula. Zero instalação."
- "Depois, nos seus projetos: instale o VS Code para trabalhar nos seus próprios arquivos."
- "Sem pressa com instalação."
- "O importante é conseguir chegar sozinho ao primeiro Olá, mundo."
- "O resto vem no seu ritmo."

### 4. Fechamento · ~25s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: editor e navegador já bastam para começar."
- "Node.js entra quando você quiser rodar código fora do navegador."
- "Na próxima aula: conhecer o VS Code por dentro."
