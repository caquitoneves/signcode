# Roteiro de vídeo — Aula 3.5: Comentários

**Módulo 3 — Primeiro Código** · Duração alvo: ~5 min
Apresentação em Libras · Apoio: legenda e transcrição em português

---

## Objetivo da aula
- Escrever comentários de uma e de várias linhas

## Termos técnicos a preparar antes
- **Comentário** — explicar: bilhete para humanos; o computador ignora.
- **// e /* */** — mostre na tela a diferença (uma linha × bloco).

## Visão geral de gravação
- **Ritmo geral:** médio; aula curta.
- **Tom predominante:** prático, com boa prática ("comente o porquê").
- **Enquadramento:** meio-corpo; o código com comentários na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~35s
*Expressão: clara · Ritmo: lento*
- "Um comentário é um bilhete para humanos lerem."
- "O computador pula essas linhas."

### 2. Como comentar · ~90s
*Expressão: didática · Ritmo: lento · Corpo: aponte cada forma*
- `[MOSTRAR NA TELA: // uma linha · código // depois do código · /* ... */ bloco de várias linhas]`
- "Duas barras: comentário de uma linha."
- "Pode vir também depois do código, na mesma linha."
- "Barra-asterisco, e asterisco-barra: comentário de várias linhas."

### 3. Boa prática · ~50s
*Expressão: conselho · Ritmo: lento*
- "Uma boa prática: comente o porquê, não o óbvio."
- `[MOSTRAR NA TELA: // soma 1 para incluir o último item (bom) × // soma 1 (não ajuda)]`
- "Explicar por que você fez algo ajuda."
- "Repetir o óbvio não ajuda."

### 4. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: duas barras comentam uma linha; barra-asterisco comenta um bloco."
- "Comentários explicam a intenção."
- "Na próxima aula: por que errar faz parte."

**Soma estimada:** ~3m15s (alvo: ~5 min)
