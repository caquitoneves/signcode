## Objetivo da aula
- Publicar o projeto no GitHub

## Termos técnicos a preparar antes
- Reaproveite git init/add/commit/push, README, GitHub Pages (Módulo 11).
- Ideia-guia: commits ao longo do caminho, não um commit gigante no fim.

## Visão geral de gravação
- **Ritmo geral:** médio.
- **Tom predominante:** de checklist prático.
- **Enquadramento:** meio-corpo; o checklist na tela.

## Roteiro (frase a frase)

### 1. Abertura · ~30s
*Expressão: clara · Ritmo: lento*
- "Com o projeto de pé, coloque-o no GitHub."
- "Com histórico e um bom README."

### 2. Checklist · ~90s
*Expressão: metódica · Ritmo: lento · Corpo: conte os itens*
- `[MOSTRAR NA TELA: git init/add/commit desde o começo · push para repo público · README · publicar no ar (Pages) e colar o link]`
- "git init, add e commit desde o começo."
- "push para um repositório público."
- "Um README explicando o projeto e como rodar."
- "E publicar no ar, com GitHub Pages, colando o link no README."

### 3. A dica do histórico · ~40s
*Expressão: conselho · Ritmo: lento*
- "Dica: commits ao longo do caminho contam a história do seu esforço."
- "Não deixe tudo para um commit gigante no fim."

### 4. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: versione desde o início, publique num repo público com README e coloque o projeto no ar."
