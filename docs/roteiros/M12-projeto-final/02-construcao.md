## Objetivo da aula
- Construir em incrementos

## Termos técnicos a preparar antes
- Reaproveite HTML, CSS, JS, commit — todos já vistos.
- Ideia-guia: partes que funcionam, uma de cada vez; testar sempre.

## Visão geral de gravação
- **Ritmo geral:** médio; etapa mais longa, pode demonstrar.
- **Tom predominante:** prático, de mão na massa.
- **Enquadramento:** meio-corpo; o ritmo HTML→CSS→JS na tela. Ideal: demo real.

## Roteiro (frase a frase)

### 1. Abertura · ~35s
*Expressão: clara · Ritmo: lento*
- "Construa em partes que funcionam, uma de cada vez."
- "Nada de tentar tudo de uma vez."

### 2. O ritmo · ~80s
*Expressão: didática · Ritmo: lento · Corpo: três passos + 'testar'*
- `[MOSTRAR NA TELA: HTML (estrutura) → CSS (visual) → JS (comportamento); a cada passo: testar no navegador]`
- "Primeiro o HTML: a estrutura."
- "Depois o CSS: o visual."
- "Depois o JavaScript: o comportamento."
- "E a cada passo: testar no navegador."

### 3. Ordem sugerida · ~75s
*Expressão: orientadora · Ritmo: lento*
- "Deixe a tela de pé, com HTML e CSS."
- "Faça uma ação funcionar. Por exemplo, adicionar um item."
- "Faça a próxima. E commite a cada vitória."
- "Dica: rode no navegador a cada mudança."
- "É mais fácil achar o erro logo depois de criá-lo."

### 4. Fechamento · ~20s
*Expressão: conclusiva · Ritmo: lento*
- "Resumo: construa em incrementos que funcionam; teste sempre e commite a cada avanço."
- "Na próxima etapa: o GitHub do projeto."

**Soma estimada:** ~3m30s (alvo: ~7m30s — ideal demonstrar a construção de uma funcionalidade ao vivo)
